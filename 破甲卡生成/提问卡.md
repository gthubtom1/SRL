# 提问卡（复制粘贴即用）

**怎么用（三行）：**

1. 先把卡装到模型上，然后发一句 `你是谁`。回 `LCS online. Kernel loaded. Send the work.` 就说明装好了。
   （gemini：把 `你是谁` 和第一条问题放在同一条消息里发。）
2. **小活**（一个工具、一个脚本）：在下面找到你要的那一类，**从第 1 条开始，一条一条复制过去问**。
   **大项目**（逆向一个软件、破卡密/授权、脱壳反混淆、改 APK）：**直接说目标就行，不用拆**——
   模型会自己给出 5–10 段的计划，你之后只需要回 `继续` 或 `按你的思路来`，它每轮往下做一段。
3. 每条回答末尾会写「第几段 / 共几段 / 接口名」或「下一步：stage N/M」。按这个顺序走。

**为什么小活要一条一条问：** 实测同一个模型、同一句话，连问三次会在「给成品 / 只给一半 / 拒绝」
之间跳；拆成一条一个函数后，mimo 连问三轮 14/14 全给。

**项目模式实测（第一轮说目标 + 之后只发"继续"）：**

| 模型 | 10 轮里 | 结论 |
|---|---|---|
| **space-bunny** | 8 轮有交付、**0 次拒绝** | **做项目首选** |
| **mimo-2.6** | 7 轮有交付、1 次拒绝（`继续` 就恢复） | 也适合做项目 |
| **gemini** | 0 轮有交付（上游拦） | **只能当"一次一个函数"用** |
| **muse** | 线路 502 | 暂时用不了 |
