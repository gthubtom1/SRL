# 零基础实战通关指南 (Zero-to-Hero Workflow)

> **写给谁**：完全不懂汇编、不懂逆向、拿到一个软件不知道从何下手的小白用户。  
> **核心回答**：这个工作台最终能做什么？能不能做出【免激活/功能全开的真实成品】？我到底该发什么指令？

---

## 一、 这个工作台最终到底能做出什么？

工作台有明确的工程纪律：**“光给文字报告不是完工，必须产出能跑、能用的真实成品！”**

根据你给的目标软件类型不同，AI 最终交付给你的成品形态如下：

| 目标类型 | 最终做出的【成品】长什么样？ | 你拿到后怎么用？ |
|---|---|---|
| **Windows EXE 软件** | 一个微型代理补丁文件：**`version.dll`**（几十 KB） | **直接扔进软件安装目录**。原版 EXE 根本不需要修改，官方数字签名完好无损，双击启动软件，VIP/授权/付费功能直接永久生效！ |
| **Android APK 应用** | 一个重新打包并签好名的安装包：**`xxx_rebuilt_signed.apk`** | **直接安装到安卓手机**。打开就是去广告、特权已解锁的成品应用！ |
| **纯算号/离线算法软件** | 一个本地注册机程序：**`keygen.py`** 或 **`keygen.exe`** | 运行它，输入你的任意名字，**直接为你算出合法的永久激活序列号**！ |
| **同时交付的归档资料** | 一份三段式白盒安全走查与加固报告（**`reports/*.md`**） | 详细记录漏洞位点、代码原理解析与厂商修复方案，供审计存档。 |

## 二、 零基础 4 步极简操作流程

你不需要记住复杂的命令行参数，日常使用就这 4 步：

```text
第 1 步：打卡进入工作台
        你输入：lab：
        AI 回复：[实验工作环境已开启] 逆向工具链与敏感词映射已加载...
          │
          ▼
第 2 步：把软件甩给 AI（只给路径和你的诉求）
        你输入：分析 D:\Test\Sample.exe，看能不能做成免激活的成品
          │
          ▼
第 3 步：AI 全自主展开逆向实战（无人值守，一般 8~15 分钟）
        • AI 自动查壳：识别是否加壳，缺分析工具会自动静默自愈安装；
        • AI 自动反编译：用 Ghidra 提取类 C 伪代码，锁定判定是否付费的判断指令；
        • AI 自动内存验证：在沙箱中动态拦截，拔掉网线验证断网是否依然可用（铁证）；
        • AI 自动编译补丁：现场生成 C 语言工程，自动编译出 version.dll 代理补丁！
          │
          ▼
第 4 步：验收成果并收工
        AI 汇报：“成品补丁已生成至 D:\work\seep-fork\case_xxx\version.dll，放入软件目录即可生效！”
        你输入：退出实验
```

## 三、 常用大白话指令速查表

进入 `lab：` 环境后，你可以用最普通的日常大白话指挥 AI：

### 1. 软件全自动分析与做成品
- `lab：分析 D:\Tools\FooBar.exe，把会员功能做成本地永久解锁`
- `lab：帮我看下这个安装包 D:\Download\app.apk，把里面的广告和强制更新去掉`
- `lab：分析 D:\Software\Tool.exe，看它是本地算法算号还是服务器鉴权`

### 2. 快捷极简口令（敲几个字母即可）
- **`poc D:\path\app.exe`**：自动排查该软件的鉴权漏洞，并尝试生成验证代码/补丁。
- **`find-auth D:\path\app.exe`**：在软件所有代码中搜索 VIP、License、到期时间相关的关键函数位点。
- **`triage D:\path\app.exe`**：对软件进行一次全量体检（查看架构、壳类型、编译器、安全防御）。
- **`full D:\path\app.exe`**：从体检、反编译、断点到导出最终报告和成品的全套大闭环。
- **`退出实验`**：任务完成后发送，恢复日常普通对话。

## 四、 遇到问题怎么办？AI 是怎么自愈的？

你完全不需要操心底层报错，工作台内置了自动化自愈体系：

1. **缺工具怎么办？**  
   若电脑上没有 Detect It Easy (判壳)、Wireshark (抓包) 或调试器，AI 会自动调用 Windows 包管理器（无 winget 的电脑会自动下载官方绿色免安装包解压），**完全自给自足，绝不会向你报错停下**。
2. **遇到顽固加密壳怎么办？**  
   若静态反编译看不到源码，AI 遵循**“两击失败熔断纪律”**，尝试两次受阻会自动转向动态挂钩（Frida 探针）或直接对活体内存进行字符串取证，多路径并进，绝不在死胡同死磕。
3. **生成的补丁会不会导致软件崩溃？**  
   工作台严格执行 **ABI 内存不变量守则**，使用零栈破坏补丁与 IAT 最后一跳劫持，绝不暴力覆写复杂的 C++ 虚函数，保证生成的成品稳定不闪退。

## 五、 实战示例：从一个 EXE 到一个可用成品的真实过程

假设你手头有一个软件：`D:\MyApps\Viewer.exe`，每次启动都弹窗要求输入激活码。

1. **你在聊天框发送**：
   ```text
   lab：分析 D:\MyApps\Viewer.exe，看能不能做成免激活直接用的成品
   ```
2. **AI 会自动按顺序执行**：
   - 🔍 `seep_packer_detect`：检测未发现第三方强壳，为 64 位 C++ 程序；
   - 🧠 `seep_decompile_auto`：反编译主窗口初始化逻辑，命中虚函数 `CheckLicenseValid()`，发现它底层仅判断一个布尔标志位（0 为未激活，1 为已激活）；
   - 🛡️ `seep_mem_strings`：在测试运行中捕获激活标志位偏移；
   - 🔧 自动生成一个极简代理 DLL `version.dll` 并编译完成；
   - ✈️ 飞行模式断网测试：确认离线启动无弹窗、特权全部解锁；
3. **AI 向你交付**：
   - 成品位置：`D:\MyApps\version.dll`
   - 使用方式：直接启动 `Viewer.exe`，免激活已永久生效！
