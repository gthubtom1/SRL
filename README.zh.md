安装器、MCP 配置或历史记录中的静态项都不等于本机已登录、已连接或已完成端到端验收。请让智能体以当前源码、实际命令输出和退出码为准，并在安装后新开宿主会话确认加载。

重复安装只更新安装所有权清单证明为受管且内容哈希仍匹配的 task/agent；更新前备份并原子替换。用户改过的或预先存在的条目不覆盖，并从 managed 所有权中排除。
