# 有界核对方式

先读 [REQUIREMENTS](../REQUIREMENTS.md) 和 [CURRENT-STATE](CURRENT-STATE.md)，明确当前待验证问题，再检查相关代码、输入和真实结果。

- 不从旧方案、历史回执或供应商材料生成产品需求。
- 不恢复已取消的域快捷指令、旧Goal或全仓补读任务。
- 每项结论给当前证据、影响、适用范围和能推翻它的对照。
- 实施者自测与独立验收分别标明；未执行、WARN和跳过不算通过。
- 输出针对具体问题的修复建议与未验证事项，不按问题数量或文档数量衡量收益。
- 不提交、发布、安装包、执行客户样本或改系统设置，除非当前任务明确包含该动作。

领域检查语义见 [DOMAIN-CONTRACT](DOMAIN-CONTRACT.md)。专业技术手册与原始证据按需读取，不另开无限审查。
