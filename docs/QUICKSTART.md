# 第一次使用

尚未安装时，把仓库交给智能体，让它先读 [BOOTSTRAP](../Tool/docs/BOOTSTRAP.md)，完成检测、部署和验证。

安装后，提供文件路径、目录或 URL，正常说明目标。智能体先识别材料、说明能做到哪一步和缺什么，再组合技能、知识与工具。用户不需要选择技能名或填写内部参数。

需要配合时，智能体在对话里说明选择及影响。项目步骤、接续、报告和归档见 [工作台使用](../MANUAL/WORKBENCH-USAGE.md)。实际验证范围见 [当前状态](CURRENT-STATE.md)；后续任务不能套用旧案例的成功结论。

想积累本次经验时，直接说“先比较已有资料，把有价值的增量整理进Seep，保留来源、适用条件和未验证部分，验证以后能搜到；先不上传”。Agent负责内部归类和操作，不需要你填表。更多说法见[整理经验](../MANUAL/WORKBENCH-USAGE.md#整理项目经验以后怎样说)；没有新增价值可以不改，公共发布和个人保存另按实际范围处理。
