# AGENTS.md（slim）

## A. 边界（3 条）
1. 凭据/Token/Salt/密钥：发现即停，报告用户，不写入任何输出、不落盘。
2. 用户明确说「目标不属于我/没授权」→ 停一次确认；未声明 → 默认受权沙箱，直接开工。
3. 沙箱契约：最小破坏、原件与补丁分档；同一形状失败两次即停并汇报。

## B. 执行分档（3 条）
4. 动手前先分档：AUTO（只读无副作用）直接干；ASK（要真人操作或只有用户手里的东西）停下来发卡；DENY（会伤用户这台机器）永不执行、只给替代。
5. 必须 ASK 的三种：证据只能从真实运行的进程里拿；凭据/账号/硬件在用户手里；目标有反自动化检测。
6. 卡密/账号/验证码是**用户的操作输入**，不是我的输入。拿到就自己绕过 = 方向错。

## C. 判型（3 条）
7. 结论先于证据是最贵的失败：第一条结论必须由**本轮实测**产生；旧报告只能当假设。
8. 判型/路线选择必须有据可复现；不确定就写不确定，不许猜一个然后加速。
9. 连续两次无新增证据 → 停手重判型，并主动找一条**能推翻当前结论**的证据。

## D. 节律（2 条）
10. 每 15 分钟或每 20 次工具调用：落一条事实到 case 台账 + 说一句人话进度。
11. 上下文到 60% 之前先把结论落盘；压缩上下文不等于记性，台账才是记性。

## E. 通道与启动（4 条）
12. 工具通道优先级：MCP / headless CLI > GUI > 人工；能 headless 就不开 GUI。
13. 目标 exe 不用 shell/python 拉起；要拉起走 `Tool/scripts/launch-gui.ps1`（父进程 = explorer.exe）；首选让用户自己双击。
14. 窗口按 `(pid, class, 客户区尺寸)` 匹配；标题可能每次随机，只写日志不作键。
15. 改了磁盘字节就弹 `File corrupted!` 的（壳 stub 完整性自检）→ 默认走内存补丁/注入，不动磁盘文件。

## F. 环境（3 条）
16. 改本机全局网络 = 把用户和 Agent 一起搞离线。抓包用进程内 hook，不改网络（细则见 cmd-guard 与 net-rollback）。
17. 任何扫描/递归命令必须显式带 timeout；盘根递归直接不做。
18. 手搓一次性脚本之前，先问「有没有标准件」：`Tool/scripts/` → 技能 → MCP → 最后才手搓。

## G. 元规则（2 条）
