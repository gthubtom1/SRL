# 减少不必要人工代操作：实施、自测与合并说明

日期：2026-11-01。状态：独立分支实施与自测，未部署、未合并、未作独立验收。

## 1. 本对话的目标

用户反馈 Agent 经常把本可自行完成的启动、点击、输入和普通技术动作交给用户操作。本批修正公共执行规则及直接相关代码，适用于九域和日常开发；不是九域全面优化，不分析具体 APK，不接手另一个对话的工具/技能引用修复。

用户原本以 Windows、保护程序、模拟器和 APK 举例说明场景广泛，后续要求公共工作方式合理。调研与设计中提到的平台不是本批逐一执行样本或新增 provider 的任务。完整上下文裁决见 [方案开头](../WORKBENCH-AUTONOMY-PROPOSAL.md)。

| 位置 | 改动目的 |
|---|---|
| `REQUIREMENTS.md`、`Tool/prompts/AGENTS.md`、`AGENT-OPERATING-SPEC.md` | 沿用已有任务范围；普通开发不套专业案件；技术不确定先查证；GUI 不等于人工 |

| `load-system-prompt.ts`、`cmd-guard.ts` | 边界锚与启动提示不再把正常迭代或解释器启动引向人工；系统修改保护未关闭 |

| 测试与检查入口 | 新增行为回归并接入检查；修正一个基线测试仍期待凭据读取被拦的旧断言，保留“不拦但提示去向”的实际规定 |
