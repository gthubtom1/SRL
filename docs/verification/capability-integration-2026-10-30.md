# 1.29.0 能力融合交付说明

这次实际增加了五个可按需读取的子技能和五个可运行的离线助手，进入原有九域结构。1.29.0 已完成当前实现全量回归、工程总检、真实部署核对和发布前复验，可作为稳定维护基线。下面列出的能力仍有明确适用边界，不能理解成全部游戏、网站、设备或云环境已经验证。

| 新入口 | 现在能做什么 | 还不能据此宣称什么 |
|---|---|---|
| 资产发现 | 整理已有 Nmap XML，去重、按范围归类主机与端口，区分未确认项 | 未执行新的网络扫描，扫描信息不等于漏洞 |
| 认证流程 | 检查去敏 OAuth/OIDC 配置之间的关系，并指导采集服务器验证证据 | 未证明真实登录、账户绑定和令牌处理均安全 |
| 源码审查 | 静态读取 Python，追踪简单输入到危险调用的候选，报告行号和未覆盖范围 | 不执行输入代码；候选不等于已复现漏洞，也不覆盖所有语言 |
| 游戏状态分析 | 比较同构建的两份内存快照，找出符合数值变化的候选偏移并保留歧义 | 不是已完成的 Trainer，不把快照偏移当进程地址 |
| 游戏渲染核对 | 按明确矩阵约定计算屏幕坐标，检查裁剪和分辨率变化 | 未实现 Hook/Overlay 绘制，也未完成真实游戏画面验收 |

现有 API 技能补了 GraphQL/WebSocket 的采集、控制组和断线恢复；云与取证技能补了已有工具接线和真实授权/实体解析的验收要求；批处理技能明确计划、执行、恢复和通知的不同结果。

当前入口是 `seep-router → 九个父领域 → 域内 subskills`。现役子技能由 30 个增加到 35 个；`_pending` 保留 22 个历史技能入口和仍被工程/旧案例引用的文件，不部署成现役顶层技能。其索引已纠正旧数量说明，并列出正式替代位置；没有为清空目录而删除历史证据。

五个助手的自检、独立正反例、CLI 错误输出保护及正式导入均已执行。最终门禁以 `HEAD=0af9d4a2`、本机实际 AgentRoot 运行：
