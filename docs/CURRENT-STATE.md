## 生效与后续使用

**本次回复结束后，在当前对话执行一次 `/reload`。** 长期运行的Piweb进程可能在新会话中复用旧模块；本轮已实测，新建会话能看到命令仍不代表最终代码已加载，reload后才出现恢复的两种模式。完整重启宿主也会重新加载。本轮未在用户正在运行的对话中途reload或回退。

日常仍通过自然语言和材料开始任务，`lab：`不是必需入口。人设文件继续由用户管理；工作台不替用户选择人设，不启用remote或更改网络设置。回退只改变会话上下文和草稿，不撤销工具产生的文件或命令效果。

后续从本页和需求文件接续，按 [EXTEND](../Tool/docs/EXTEND.md)、[技能编写指南](../MANUAL/SKILL-CREATION-GUIDE.md) 与 [稳定基线维护](../MANUAL/BASELINE-FREEZE.md) 做具体技能、缺陷或上游适配的小步维护。不要从旧报告恢复已取消的域快捷卡或重新启动大范围改造。

本轮部署环境为Windows、PowerShell、Git Bash及当前Piweb内嵌SDK；SDK1.4.0是独立的管理安装，未替换Piweb宿主。没有据此宣称原生Linux/macOS、任意第三方强制提示词、provider缓存费用、所有商业保护或真机任务已验证。

专业结论只对实际目标、版本与材料成立。Core保证身份、记录与接续一致性，不能单独证明任意分析文字的专业真伪；`project_workflow`仍是 `workflow-entry-only`。既有事实、合成传输验证和真实宿主界面证据分别报告，不相互冒充。

如需复查，从仓库根运行对应专项或正式入口，始终使用同一AgentRoot：

