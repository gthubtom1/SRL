> 目的：把「够深」变成可数的三条门槛，并记录每个域的差距。
> 数据来源：三个同类仓库**实拉下来量的**（不是看描述）。

**结论（这就是 A+ 的量级）**：一个领域的深度 ≈ **1,500–2,500 行**，拆成 **4–10 篇**，
篇均 **250–500 行**，**每篇至少一个可执行命令块**，并且**每域有一份经验回流**（lessons/field-journal）。

## 2. A+ 三条门槛（可机检）

| # | 门槛 | 判据 | 为什么是这条 |
| :-: | :-- | :-- | :-- |
| **A1 总量** | 域 `references` 总行数 **≥ 2,000** | 现算 | 外部单主题就 1,200–2,500 行；低于 2,000 说明只写了目录 |
| **A2 密度** | 篇均 **≥ 250 行** | 现算 | 我们的 8 篇/937 行 = 117 行/篇 → 那是"提纲"，不是技法 |
| **A3 动作** | **每篇都有命令块**，且每篇至少 1 条"期望输出" | 判据「技法页命令棘轮」 | 没有命令 = 模型无法执行，只能凭感觉 |

**加分项（不强制，但 A+ 通常都有）**：经验回流文件（`lessons.md`）、症状索引、可枚举矩阵（AD/AV 式）。

## 4. 补法（按域推进，每域一次做透）

每个域要达到 A+，标准动作是**三件套**：

| 动作 | 产出 | 判据 |
| :-- | :-- | :-- |
| ① **补技法篇** | 把"提纲级"的 8 篇扩成 4–10 篇、篇均 ≥250 行 | A1 + A2 |
| ② **每篇加命令 + 期望输出** | 至少 1 个可复制命令块 + "通过长什么样" | A3 |
| ③ **补经验回流** | `references/lessons.md`：本域踩过的坑（现象/原因/正确动作） | 加分项 |
