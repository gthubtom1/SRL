# Web 签名参数还原（补环境 → 复算 → 重放验证）
- 触发词：Web 签名、sign 参数、加密参数、补环境、js reverse、复算、重放
- 输入（用户提供）：`<url>`、`<目标请求>`、`<账号或 cookie 占位>`、`<抓包文件>`、`<期望响应字段>`；范围由用户提供的 scope 决定。
- 用到的能力（capability id）：`repo:case_state` `repo:kb-query` `repo:web-check` `repo:web-repro` `repo:web-accept` `repo:probe_api` `tool:fiddler` `tool:tshark` `mcp:js-reverse`
- 步骤：1) `python Tool/scripts/case_state.py init --case work/<case> --target <TARGET>`；2) `python Tool/skill/web-pentest/scripts/web-check.py --url <URL> --out work/<case>/artifacts/page.json`，`page.json` 顶层直接含 `url`/`status`/`headers`（脚本 URL、cookie 与目标请求的 initiator 不在本步产出，见第 4 步）；3) `python Tool/skill/web-pentest/scripts/kb-query.py --query "补环境" --limit 20`，把命中的补环境/签名条目抄进 `work/<case>/notes.md`；4) 用 js-reverse MCP 抓签名，工具名按序（产物全部落 `work/<case>/artifacts/`）：`mcp__js_reverse__select_page` 选中已开页面（没有则先 `mcp__js_reverse__new_page` 打开 `<URL>`）→ `mcp__js_reverse__list_scripts` 取脚本列表写 `scripts.json`（拿到脚本 URL/sourceMap）→ `mcp__js_reverse__break_on_xhr` 在 `<目标请求>` 上设断点，命中后调用栈写 `trace.json` → `mcp__js_reverse__get_request_initiator` 定位发起函数写 `initiator.json` → `mcp__js_reverse__evaluate_script` 在断点帧里取明文入参与返回值写 `sign_inputs.json`；随后 `python Tool/scripts/case_state.py claim --case work/<case> --id S1 --text "sign 由 <func> 生成" --status hypothesis`，`python Tool/scripts/case_state.py prove --case work/<case> --id S1 --evidence work/<case>/artifacts/initiator.json`；5) 复算：用第 4 步 `evaluate_script` 取到的明文入参（`sign_inputs.json`）在本地 Node 跑 `sign.js` + `env.js` 三遍，把三次 sign 与抓包原值一起写 `work/<case>/artifacts/sign_check.json`（`web-repro` 只负责重放；签名复算在本步的本地 Node 里做，两者分开）；6) 重放：`python Tool/skill/apkseep/scripts/probe_api.py --base <API_BASE> --path <PATH> --param <sign=...> --header <cookie:...>`，响应字段与期望一致；注入类重放另跑 `python Tool/skill/web-pentest/scripts/web-repro.py --probe work/<case>/artifacts/probe.json --out work/<case>/artifacts/replay.json`；7) `python Tool/skill/web-pentest/scripts/web-accept.py --case <case>`，最后 `python Tool/scripts/preflight.py --fast`。
- 判据：page.json 含 url、status、headers；work/<case>/artifacts/ 下 scripts.json、trace.json、initiator.json、sign_inputs.json 均在；sign_check.json 中三次复算 sign 全等且与抓包 s…｜不行就换：本地报 window/document/navigator is not defined → 按 first divergence 逐个补，单次只补一个对象；sign 不等 → 回步骤 4 取同一请求的完整入参与环境版本
