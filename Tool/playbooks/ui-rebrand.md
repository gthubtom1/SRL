# UI 改版与去品牌
- 触发词：UI 改版、换品牌、去作者、去联系方式、换图标、换文案、关于页
- 输入（用户提供）：`<target.exe/apk/asar>`、`<品牌名>`、`<图标与配色>`、`<要替换的页面清单>`、`<保留的功能清单>`；范围由用户提供的 scope 决定。
- 用到的能力（capability id）：`tool:resourcehacker` `tool:imhex` `tool:pe-bear` `apk:static_apktool` `apk:repack_signed` `repo:case_state` `repo:preflight-classify` `repo:patch-verify` `repo:reverse-accept` `repo:install_test`
- 步骤：1) `python Tool/skill/softseep/scripts/preflight-classify.py <TARGET> --hint`，确认 UI 栈（自绘/Win32/Qt/Web/Android）；2) 逐页截图与文案清单写 `work/<case>/ui-inventory.md`，`python Tool/scripts/case_state.py claim --case work/<case> --id U1 --text "页面/控件/文案清单已齐" --status hypothesis` 后 `prove --id U1 --evidence work/<case>/ui-inventory.md`；3) 资源/字符串改动写 `work/<case>/patch.json`（等长替换优先），`python Tool/skill/softseep/scripts/patch-verify.py --file <TARGET> --manifest work/<case>/patch.json --out work/<case>/out/<name>`；4) Android 分支：`powershell -File Tool/scripts/apk/decode.ps1 -ApkPath <apk> -Name <case> -OutRoot work/<case>`，改 `res/`、`strings.xml`、图标后用 `powershell -File Tool/scripts/apk/rebuild-sign-install.ps1 -ProjectDir <project> -OutDir work/<case>/out -Install`；5) 去品牌复查：`python Tool/skill/malware-analysis/scripts/mal-triage.py --file <OUT> --json`，从字符串段确认作者名/邮箱/QQ/二维码/更新地址已替换或移除；6) 回归：`python Tool/skill/softseep/scripts/reverse-accept.py --case <case>`，APK 再跑 `python Tool/skill/apkseep/scripts/install_test.py --apk <OUT> --pkg <pkg> --activity <activity> --shots work/<case>/shots`；7) `python Tool/scripts/preflight.py --fast`。
- 判据：ui-inventory.md 每页有 before/after 截图；patch.json 每条改动可回滚且 patch-verify ok=true；mal-triage 字符串段无原作者标识；功能清单逐项通过；APK 安装启动截图与 EXE 主界面一致；reverse-accept rc=0。｜不行就换：只改窗口标题 → 回步骤 2 补页面/控件清单；资源槽位编号变化 → 按容器条目哈希匹配并记 old→new
