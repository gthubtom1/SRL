# 跨版本追版（AOB 滑窗）
- 触发词：追版、跨版本、新版本、AOB、滑窗、位点对齐、版本账、迁移
- 输入（用户提供）：`<旧版 exe>`、`<新版 exe>`、`<旧版版本号>`、`<新版版本号>`、`<旧版 manifest.json>`、`<验收清单>`；范围由用户提供的 scope 决定。
- 用到的能力（capability id）：`tool:ida` `tool:x64dbg` `tool:r2` `repo:case_state` `repo:patch-verify` `repo:reverse-accept`
- 步骤：1) `rabin2 -I <NEW_EXE>`，记录 format/machine/bintype；与旧账不一致时先回 `license-bypass-deliver` 的过壳路线；2) 旧位点逐条入账：`python Tool/scripts/case_state.py claim --case work/<case> --id SITE-1 --text "<语义> @ RVA 0x…（窗口 32B, orig=<hex>）"`；3) 新版本定位同一段 AOB：`rabin2 -q -c "/x <hex>" <NEW_EXE>`（或 r2 `seep_r2_cmd`）→ 必须唯一命中，截图/输出落 `work/<case>/aob.json` 后 `case_state.py prove --id SITE-1 --evidence work/<case>/aob.json`；4) 对照表：把旧 RVA→新 RVA 写 `work/<case>/align.json`，`case_state.py claim --case work/<case> --id ALIGN --text "N/N 唯一命中"` 再 `prove --id ALIGN --evidence work/<case>/align.json`；5) 补丁落地后 `python Tool/skill/softseep/scripts/patch-verify.py --manifest work/<case>/patch.json --out work/<case>/patch-verify.json`；6) `python Tool/skill/softseep/scripts/reverse-accept.py --case <case>`，最后 `python Tool/scripts/preflight.py --fast`。
- 判据：align 输出 miss=0、multi=0、命中率 N/N；report 存在且每条位点有旧/新 RVA；patch-verify ok=true 且 result_sha256 复算一致；验收清单逐项通过；reverse-accept rc=0。｜不行就换：packer_hint 新增壳告警 → 停追版，先过壳；multi → 加长 window 或加相邻唯一字节
