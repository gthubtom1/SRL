# 跨版本追版（AOB 滑窗）
- 触发词：追版、跨版本、新版本、AOB、滑窗、位点对齐、版本账、迁移
- 输入（用户提供）：`<旧版 exe>`、`<新版 exe>`、`<旧版版本号>`、`<新版版本号>`、`<旧版 manifest.json>`、`<验收清单>`；范围由用户提供的 scope 决定。
- 用到的能力（capability id）：`tool:ida` `tool:x64dbg` `tool:r2` `repo:case_state` `repo:migrate` `repo:patch-verify` `repo:reverse-accept`
- 步骤：1) `python Tool/scripts/migrate.py fingerprint <NEW_EXE>` → rc=0，记录 format/machine/packer_hint；与旧账不一致时先回 `license-bypass-deliver` 的过壳路线；2) `python Tool/scripts/migrate.py init --case work/<case> --exe <OLD_EXE> --version <OLD_VER>` → rc=0；3) 旧位点逐条入账：`python Tool/scripts/migrate.py add-site --case work/<case> --version <OLD_VER> --id <SITE_ID> --sem <SEM> --rva <RVA> --window 32 --kind <kind> --orig <hex> --new <hex>` → rc=0；4) `python Tool/scripts/migrate.py align --case work/<case> --old <OLD_VER> --new <NEW_EXE> --new-version <NEW_VER>` → rc=0，输出必须 `N/N 唯一命中`；5) `python Tool/scripts/migrate.py report --case work/<case> --old <OLD_VER> --new-version <NEW_VER>` → rc=0，报告含旧 RVA→新 RVA 对照、命中率、需人工项；6) 新位点重建产物后 `python Tool/skill/softseep/scripts/patch-verify.py --file <NEW_EXE> --manifest work/<case>/versions/<NEW_VER>/patch.json --out work/<case>/out/<name>` → rc=0；7) `python Tool/skill/softseep/scripts/reverse-accept.py --case <case> --json` → rc=0，最后 `python Tool/scripts/preflight.py --fast` → rc=0。
- 判据（可机检）：`align` 输出 `miss=0`、`multi=0`、命中率 `N/N`；`report` 存在且每条位点有旧/新 RVA；`patch-verify ok=true` 且 `result_sha256` 复算一致；验收清单逐项通过；`reverse-accept` rc=0。
- 失败判据 + 换路：`packer_hint` 新增壳告警 → 停追版，先过壳；`multi` → 加长 window 或加相邻唯一字节；`miss` → 走唯一字符串锚、xref 回溯、反编译特征三重；判定逻辑改写 → 回 `license-bypass-deliver` 重判权威；新版服务端接口变化 → 转 `backend-rebuild`。
- 交付物：`work/<case>/versions/<OLD_VER>/manifest.json`、`versions/<NEW_VER>/manifest.json`、`patch.json`、`out/<name>`、`migration-report.md`、`acceptance/`。
