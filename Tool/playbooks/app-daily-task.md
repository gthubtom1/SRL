# APP 每日任务 / 积分（Android 抓包 + 签名 + 重放）
- 触发词：APP 每日任务、积分、签到、任务列表、重放、Android、frida、小程序、微信小程序、wxapkg
- 输入（用户提供）：`<apk>`、`<pkg>`、`<activity>`、`<设备 serial>`、`<账号占位>`、`<抓包文件>`、`<接口基址>`；范围由用户提供的 scope 决定。
- 用到的能力（capability id）：`apk:static_dex` `apk:frida_dynamic` `apk:frida_rpc` `apk:repack_signed` `apk:device_static` `repo:case_state` `repo:pcap-summary` `repo:run_probe` `repo:probe_api` `repo:install_test` `tool:jadx` `tool:apktool` `tool:frida` `tool:tshark`
- 步骤：1) `python Tool/skill/apkseep/scripts/doctor.py --capabilities --json`，确认 adb、frida、apksigner、设备四类原子可用；2) `powershell -File Tool/scripts/apk/decode.ps1 -ApkPath <apk> -Name <case> -OutRoot work/<case>`，拿到 jadx 与 apktool 两棵树；3) `python Tool/skill/apkseep/scripts/run_probe.py <probe.js> --pkg <pkg> --via usb --device <serial> --log work/<case>/probe.log`，记录任务列表与领奖函数入参；4) `python Tool/skill/protocol-plugin/scripts/pcap-summary.py --file <capture.pcap> --extract work/<case>/net --json`，把任务、签到、领奖三类请求与响应配对；5) `python Tool/skill/apkseep/scripts/frida_rpc_serve.py --script <rpc.js> --package <pkg> --mode call --export sign --args '["<payload>"]'`，用设备侧签名复算一次；6) `python Tool/skill/apkseep/scripts/probe_api.py --base <API_BASE> --path <task_path> --header <auth:...> --param <param>`，重放同一请求并对照积分变化；7) `python Tool/skill/apkseep/scripts/install_test.py --apk <apk> --pkg <pkg> --activity <activity> --shots work/<case>/shots`，确认安装态与运行态一致；8) `python Tool/scripts/case_state.py deliver --case work/<case> --level M2 --evidence work/<case>/replay.json`。
- 判据：probe.log 中 sign 入参与抓包同形；replay.json 三次响应 code=0 且 points_delta 一致；install_test 截图含任务完成态；doctor.py 的 repack_signed 与 frida_dynamic 非 blocked。｜不行就换：SSL pinning 拒绝 → 走 frida 内存侧签名；模拟器/root 检测 → 换真机并记录
