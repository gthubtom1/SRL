# 逆向测绘报告（结构 / 壳 / 权威 / 钥匙）
- 触发词：逆向测绘、结构、壳、权威、钥匙、可行性、报告、开工前
- 输入（用户提供）：`<target.exe/apk/elf>`、`<样本来源与哈希>`、`<账号或授权占位>`、`<观测仪器清单>`、`<报告目录>`；范围由用户提供的 scope 决定。
- 用到的能力（capability id）：`tool:diec` `tool:capa` `tool:floss` `tool:ida` `tool:r2` `repo:case_state` `repo:seep-start` `repo:preflight-classify` `repo:pwn-check` `repo:driver-triage` `repo:kb-query` `repo:reverse-accept`
- 步骤：1) `python Tool/skill/softseep/scripts/preflight-classify.py <TARGET> --hint` → rc=0，记录 platform/protection/sections/suggested_type；2) `python Tool/scripts/pwn-check.py --file <TARGET> --json` → rc=0，记录保护位、危险导入、format 串风险与利用路线；3) 内核驱动目标加跑 `python Tool/scripts/driver-triage.py --file <TARGET.sys> --json` → rc=0，记录设备名/IOCTL/风险分；4) `python Tool/scripts/kb-query.py --query "<壳/家族/授权>" --limit 20` → rc=0，把可复用判据补进 `notes.md`；5) 仪器与深度逐项登记：`python Tool/scripts/case_state.py instrument --case work/<case> --name <name> --status <ok/blocked/partial> --note "<结论>"` → rc=0，`depth --level D0..D5 --result <pass/fail>` → rc=0；6) 可行性裁定：`python Tool/scripts/case_state.py verdict --case work/<case> --value <可赢/部分可赢/不可赢> --tier <T1/T2/T3> --note "<依据>"` → rc=0；7) `python Tool/skill/softseep/scripts/reverse-accept.py --case <case> --json` → rc=0，最后 `python Tool/scripts/preflight.py --fast` → rc=0。
- 判据（可机检）：报告八节齐全；`preflight-classify.json` 有 platform/protection/sections；`pwn-check.json` 有保护位与导入；`case_state show` 至少 2 种仪器且有 1 种非 baseline 可用；D0–D5 均有 pass/fail；`verdict` 明确；`reverse-accept` rc=0。
- 失败判据 + 换路：判不出壳 → 按自定义壳处理，转行为/外部观测；字符串少且高熵 → 先脱壳或 dump；权威不明 → 抓首个网络请求并做断网对照；钥匙找不到 → 记录“缺哪把、何时产生”；仪器全阻断 → 转外部观测/网络层，不硬上注入。
- 交付物：`work/<case>/report.md`（8 节）、`facts.jsonl`、`probe.json`、`case.json`、`authority.md`、`key-map.json`。
