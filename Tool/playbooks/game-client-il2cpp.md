# 游戏客户端 IL2CPP / global-metadata / AssetBundle 取证

- 触发词：il2cpp、global-metadata、GameAssembly、UnityFramework、AssetBundle、unity3d、Unity 客户端、Unity 游戏、Mono、dump.cs、Il2CppDumper、Cpp2IL
- 输入（用户提供）：`<客户端包或安装目录>`、`<进程或内存 dump>`、`<Unity 版本线索>`、`<要定位的字段/协议/资源>`；范围由用户提供的 scope 决定。
- 用到的能力（capability id）：`repo:case_state` `repo:kb-query` `forensics:evidence_accept` `forensics:check` `tool:ida` `tool:ghidra`
- 步骤：1) `python Tool/scripts/case_state.py init --case work/<case> --target <客户端包>` → rc=0，落案例与只读副本哈希；2) `python Tool/skill/forensics-mobile/scripts/forensics-check.py --file <客户端包或目录> --json --out work/<case>/artifacts` → rc=0，得类型/哈希/时间线；3) 按 `references/game-client-il2cpp.md` 判 Mono 还是 IL2CPP：`Managed/Assembly-CSharp.dll` 走 `ilspycmd`，只有 `GameAssembly*`/`UnityFramework` + `global-metadata.dat` 走 IL2CPP；4) IL2CPP 分支先校元数据头（`0xFAB11BAF` + 版本）与 Unity 版本一致，再 `Il2CppDumper GameAssembly.dll global-metadata.dat out/` 产出 `dump.cs`/`script.json`/`il2cpp.h`；5) 资源分支 `xxd -l 64 data.unity3d` 确认 `UnityFS`/`UnityWeb` 头，再用 AssetStudioModCLI/AssetRipper/UnityPy 导出；6) `python Tool/skill/web-pentest/scripts/kb-query.py --query il2cpp --limit 10` → rc=0，拿同版本战例与踩坑；7) 偏移落地到 IDA/Ghidra 后记录客户端版本+哈希+工具版本；8) `python Tool/skill/forensics-mobile/scripts/evidence-accept.py --case work/<case> --domain forensics-mobile --json` → rc=0。
- 判据（可机检）：`forensics-check.json` 含 `sha256`、`type`、`timeline`；`evidence-accept` rc=0 且 `ok=true`；`dump.cs` 的字段/方法与 `script.json` 地址、运行时内存值三者能对上（对不上标 `unverified`，不写成结论）；AssetBundle 导出清单与运行时加载的 bundle 名一致。
- 失败判据 + 换路：只有 DummyDll、找不到 `global-metadata.dat` → 换 `Memory` 域做内存镜像，再从镜像里扫 `0xFAB11BAF`；元数据版本与 `GameAssembly` 不符 → 记录版本后标 `unverified`，按 `version-migrate` 取对应版本工具；导出为空/资源加密 → 转 `firmware-extract` 的资源容器思路或按 `protocol-replay` 抓下发；需要改内存/注入时按用户提供的授权任务走对应域，本配方只做取证与关系说明。
