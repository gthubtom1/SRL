# 多账号批量执行器（池 / 限速 / 幂等 / 通知）
- 触发词：多账号、批量、账号池、并发、限速、幂等、通知、重试
- 输入（用户提供）：`<ACCOUNTS_JSON>`、`<并发数>`、`<QPS>`、`<任务名>`、`<通知 webhook>`、`<失败重试次数>`；范围由用户提供的 scope 决定。
- 用到的能力（capability id）：`repo:case_state` `repo:check-budget` `repo:env-ledger` `repo:preflight` `repo:pcap-summary` `repo:probe_api` `tool:fiddler` `tool:tshark`
- 步骤：1) `python Tool/scripts/budget.py`，确认批量器没有把仓库预算撑爆；2) `python Tool/scripts/case_state.py init --case work/<task> --target <TASK>`，建案例与状态；3) 批量器落到 `work/<task>/runner.py`，账号池只从 `ACCOUNTS_JSON` 读，先跑 1 个账号，`python Tool/skill/apkseep/scripts/probe_api.py --base <BASE> --path <TASK_PATH> --header <auth:...>`，确认单账号基线；4) 每批结束 `python Tool/scripts/case_state.py prove --case work/<task> --id A<batch> --evidence work/<task>/batch-<batch>.json`，记录耗时、成功数、限速命中数；5) 幂等键写 `work/<task>/idem.json`，`python Tool/scripts/case_state.py claim --case work/<task> --id I1 --text "同一任务同一账号只执行一次" --status hypothesis`，重复跑后 `prove --id I1 --evidence work/<task>/idem.json`；6) 代理/hosts/时间等环境改动先记账：`python Tool/skill/softseep/scripts/env-ledger.py record --case work/<task> --action "<change>" --before <before> --after <after> --restore "<restore>"`，收尾 `python Tool/skill/softseep/scripts/env-ledger.py check --case work/<task>`；7) 汇总通知写 `work/<task>/notify.json`，`python Tool/scripts/case_state.py deliver --case work/<task> --level M2 --evidence work/<task>/notify.json`，最后 `python Tool/scripts/preflight.py --fast`。
- 判据：批跑配置里 qps/retry 不超过设定值；idem.json.duplicate_submits=0；env-ledger check rc=0；notify.json 含成功/失败/限速三组计数。｜不行就换：429 集中出现 → 降 QPS、增加抖动并改串行；账号封禁/验证码 → 立即停该池并转 captcha-handling
