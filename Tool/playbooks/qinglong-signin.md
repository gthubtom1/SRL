# 青龙面板签到 / 任务脚本
- 触发词：青龙、qinglong、签到、定时任务、cron、env、多账号、通知、小程序、微信小程序
- 输入（用户提供）：`<site>`、`<QL_URL>`、`<QL_TOKEN>`、`<COOKIE_1..N>`、`<账号 JSON>`、`<通知 webhook>`、`<抓包文件>`；范围由用户提供的 scope 决定，凭据只写 env 占位。
- 用到的能力（capability id）：`repo:case_state` `repo:pcap-summary` `repo:probe_api` `repo:tls_check` `repo:check-budget` `repo:env-ledger` `repo:preflight` `tool:fiddler` `tool:tshark` `tool:dumpcap`
- 步骤：1) `python Tool/scripts/case_state.py init --case work/qinglong-<site> --target <SITE_URL>`，生成 case.json 与 state；2) `python Tool/skill/protocol-plugin/scripts/pcap-summary.py --file <capture.pcap> --extract work/qinglong-<site>/net --json`，从 hosts 与 snippets 锁定签到、登录、通知请求；3) `python Tool/skill/apkseep/scripts/probe_api.py --base <SITE_URL> --path <signin_path> --param <param> --header <name:value>`，确认端点、方法、必需头与返回码；`python Tool/skill/apkseep/scripts/tls_check.py <SITE_HOST> --json`，证书链与 SNI 入证据；4) `python Tool/skill/web-pentest/scripts/kb-query.py --query "sign" --limit 20`，把签名/风控条目抄进 `work/qinglong-<site>/notes.md`，签名函数落到 `work/qinglong-<site>/signin.py`；单账号试跑后 `python Tool/scripts/case_state.py prove --case work/qinglong-<site> --id S1 --evidence work/qinglong-<site>/run.json`；5) 多账号前 `python Tool/skill/softseep/scripts/env-ledger.py record --case work/qinglong-<site> --action "写入青龙 env 占位" --before none --after present --restore "echo noop"`，`python Tool/skill/softseep/scripts/env-ledger.py check --case work/qinglong-<site>` 通过；rc=1 表示还有未还原项，先按 check 输出逐项恢复再继续（不要带未还原项往下走）；同日跑两次后 `python Tool/scripts/case_state.py claim --case work/qinglong-<site> --id I1 --text "同日二次执行命中幂等键" --status hypothesis` 并用 `prove --id I1 --evidence work/qinglong-<site>/idem.json`；6) 结果与通知写 `work/qinglong-<site>/notify.json`，`python Tool/scripts/case_state.py deliver --case work/qinglong-<site> --level M2 --evidence work/qinglong-<site>/notify.json`，最后 `python Tool/scripts/budget.py` 与 `python Tool/scripts/preflight.py --fast` 均 rc=0。
- 判据：run.json.ok=true；run.json.sign 与抓包样本一致；idem.json.duplicate_submits=0；notify.json.status=sent；case_state show 的 S1/I1 均为 proven。｜不行就换：登录 401/302 回登录页 → 换 cookie 获取方式或重抓登录链；签名不一致 → 回步骤 2 取同一请求的完整参数
