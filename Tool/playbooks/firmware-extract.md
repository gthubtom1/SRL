# 固件提取 + rootfs 判据
- 触发词：固件提取、固件解包、rootfs、squashfs、UBI、JFFS2、binwalk、镜像、UART、串口、shell、OTA、电视盒子、车机、分区表
- 输入（用户提供）：`<firmware.bin>`、`<设备型号>`、`<来源与哈希>`、`<提取输出目录>`、`<架构线索>`；范围由用户提供的 scope 决定。
- 用到的能力（capability id）：`tool:binwalk` `repo:case_state` `repo:fw-triage` `repo:fw-repro` `repo:fw-accept` `repo:kb-query`
- 步骤：1) `python Tool/scripts/case_state.py init --case work/<case> --target <TARGET>`，记录来源、哈希与只读副本；2) `python Tool/skill/firmware-iot/scripts/fw-triage.py --file <FW> --json --out-dir work/<case>/fw`，输出 magic/container/entropy/凭据线索与建议解包命令；3) `python Tool/skill/firmware-iot/scripts/fw-repro.py --file <FW> --out-dir work/<case>/fw --json`，执行 carve/extract 并输出 rootfs 证据；4) rootfs 判据：`work/<case>/fw/rootfs` 同时含 `/etc`、`/bin` 或 `/usr/bin`、`/lib`，把目录树写 `work/<case>/rootfs-manifest.json`，`python Tool/scripts/case_state.py claim --case work/<case> --id F1 --text "rootfs 三目录齐全且架构自洽"` 后 `prove --id F1 --evidence work/<case>/rootfs-manifest.json`；5) `python Tool/skill/web-pentest/scripts/kb-query.py --query "squashfs" --limit 10`，把容器/文件系统条目补进 `notes.md`；6) `python Tool/skill/firmware-iot/scripts/fw-accept.py --case <case> --json`，最后 `python Tool/scripts/preflight.py --fast`。
- 判据：fw-triage.json 有 containers 与 entropy.overall；fw-repro.json 的 rootfs.dirs 含 etc/bin/lib；rootfs-manifest.json 的 file_count>0 且 arch 与 readelf 输出一致；fw-a…｜不行就换：全盘高熵无 strong magic → 判加密/厂商容器，转 UART/JTAG 在线读；只切出 kernel/DTB → 用真实偏移重算，换 sasquatch/ubireader/jefferson/7z
