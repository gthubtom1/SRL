# APK 去广告 / 去弹窗
- 触发词：APK 去广告、去弹窗、开屏、插屏、Banner、激励视频、广告 SDK、套壳、H5 套壳
- 输入（用户提供）：`<apk>`、`<pkg>`、`<activity>`、`<设备 serial>`、`<广告出现场景>`、`<保留功能清单>`；范围由用户提供的 scope 决定。
- 用到的能力（capability id）：`apk:static_dex` `apk:smali_roundtrip` `apk:repack_signed` `apk:device_static` `repo:case_state` `repo:doctor` `repo:apk-decode` `repo:dex_strings` `repo:patch_smali` `repo:rebuild-sign-install` `repo:install_test` `repo:apk_diff` `tool:jadx` `tool:apktool`
- 步骤：1) `python Tool/skill/apkseep/scripts/doctor.py --capabilities --json`，确认 static_apktool、smali_roundtrip、repack_signed、device_static 四类原子；2) `powershell -File Tool/scripts/apk/decode.ps1 -ApkPath <apk> -Name <case> -OutRoot work/<case>`，得到 jadx/apktool 两棵树；3) `python Tool/skill/apkseep/scripts/dex_strings.py work/<case>/<case>/apktool --find "ads|advert|interstitial|splash|popup|reward" --per-file`，列出广告类与弹窗类候选；4) 写 `work/<case>/patch.json`（file/method/registers/body），先 `python Tool/skill/apkseep/scripts/patch_smali.py <smali_tree> work/<case>/patch.json --dry-run`，再跑同命令去掉 `--dry-run`；5) `powershell -File Tool/scripts/apk/rebuild-sign-install.ps1 -ProjectDir <project> -OutDir work/<case>/out -Install -DeviceSerial <serial>`；6) `python Tool/skill/apkseep/scripts/install_test.py --apk work/<case>/out/<name>.apk --pkg <pkg> --activity <activity> --shots work/<case>/shots`，按广告场景逐页截图；7) `python Tool/skill/apkseep/scripts/apk_diff.py <original.apk> work/<case>/out/<name>.apk --summary`，确认只动了预期条目；8) `python Tool/scripts/case_state.py deliver --case work/<case> --level M2 --evidence work/<case>/diff.json`。
- 判据：patch.json 每条方法唯一命中且 assembler 通过；apk_diff --summary 的 changed 条目只在预期范围；install_test 截图中广告场景不再出现，保留功能逐项可用；doctor.py 的 repack_signed 非 blocked。｜不行就换：广告配置由服务端下发 → 在 scope 内改 hosts/代理并记录，或转 backend-rebuild；广告在 native/SDK → 用 elf_plt/so_constpatch 定位加载点
