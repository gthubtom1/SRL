# 验证码三条处置（识别 / 交互 / 人工）
- 触发词：验证码、captcha、OCR、滑块、点选、图形码、短信码、人机校验、Cloudflare、人机验证
- 输入（用户提供）：`<url>`、`<app pkg>`、`<验证码图片或页面截图>`、`<提交端点>`、`<账号占位>`、`<可用人工时长>`；范围由用户提供的 scope 决定。
- 用到的能力（capability id）：`repo:case_state` `repo:web-check` `repo:temp_ocr` `captcha-gap` `captcha-angle` `repo:run_probe` `repo:frida_rpc_serve` `repo:probe_api` `tool:frida` `tool:fiddler` `mcp:playwright`
- 步骤：1) `python Tool/skill/web-pentest/scripts/web-check.py --url <URL> --out work/<case>/page.json`，记录验证码类型、脚本来源、提交端点与 cookie 形态；2b) 滑块类：`python Tool/skill/web-pentest/scripts/captcha-gap.py --bg <背景图> --slice <滑块图> --json --out work/<case>/gap.json`；2c) 旋转类：`python Tool/skill/web-pentest/scripts/captcha-angle.py --image <旋转图> --json --out work/<case>/angle.json`；2) 识别路线：`powershell -File Tool/scripts/temp_ocr.ps1 -ImagePath <captcha.png>`，输出文本与置信度写入 `work/<case>/ocr.json`，低置信度直接走第 3 或第 4 步；3) 交互路线：`python Tool/skill/apkseep/scripts/run_probe.py <hook.js> --pkg <pkg> --via usb --log work/<case>/captcha.log`，抓取挑战参数、轨迹与提交函数；4) 需要复算时 `python Tool/skill/apkseep/scripts/frida_rpc_serve.py --script <rpc.js> --package <pkg> --mode call --export solve --args '["<challenge>"]'`，拿到票据；5) 人工路线：截图与挑战原文写 `work/<case>/human-queue.json`，`python Tool/scripts/case_state.py gaps --case work/<case> --add --id C1 --missing "human solve queue" --impact "blocking" --repairable yes --alt "人工输入"`，紧接 `python Tool/scripts/case_state.py claim --case work/<case> --id C1 --text "<结论>" --status hypothesis`（先把 C1 登记成 claim，prove 才找得到它），人工回填后跑 `python Tool/scripts/case_state.py prove --case work/<case> --id C1 --evidence work/<case>/human-queue.json`；6) 票据提交：`python Tool/skill/apkseep/scripts/probe_api.py --base <BASE> --path <SUBMIT_PATH> --token <TICKET> --header <cookie:...>`，确认一次性有效；7) `python Tool/scripts/case_state.py deliver --case work/<case> --level M2 --evidence work/<case>/ticket.json`。
- 判据：gap.json 有 x 与 confidence（滑块类）；angle.json 有 angle/angle_mod90 与 confidence（旋转类）；ocr.json 有 text 与 confidence；captcha.log 有挑战参数与提交调用；ticket.json.accept…｜不行就换：OCR 置信度低于阈值 → 交互或人工；滑块/行为轨迹 → 人工为主，交互只取参数
