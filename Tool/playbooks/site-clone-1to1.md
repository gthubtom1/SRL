# 网站 1:1 复刻（crawl → rebuild → pixel/DOM/network diff → backend 标注）
- 触发词：1:1 复刻、整站克隆、crawl、像素对比、DOM diff、network diff、后端标注、断网、mock、离线、SaaS、本地版
- 输入（用户提供）：`<URL>`、`<case>`（`Tool/cases/<case>` 案例目录，需含 `case.json` 与 `input/scope.txt`）、`<登录态 cookie 占位>`、`<允许抓取的路径前缀>`、`<目标分辨率>`、`<本地端口>`；范围由用户提供的 scope 决定，未授权路径按 scope 排除。
- 用到的能力（capability id）：`probe:site-crawl` `probe:site-rebuild` `probe:visual-diff` `probe:site-accept` `repo:preflight`
- 步骤：1) 当前安装态不部署、不索引、不路由 `_pending/`；以下命令只能在源码工作区人工运行，不能由安装后的智能体当作自动工具调用。`python Tool/skill/_pending/site-clone/scripts/site-crawl.py --url <URL> --out Tool/cases/<case>/artifacts/crawl --max-pages 20 --max-depth 3 --rps 2 --allow-host <ALLOW_HOST>`，产出 `site-graph.json`、`pages/`、`screenshots/`、`api/`，核对 `coverage.missing_rate<=0.02`；2) 仅源码工作区人工运行 `python Tool/skill/_pending/site-clone/scripts/site-rebuild.py --crawl Tool/cases/<case>/artifacts/crawl --out Tool/cases/<case>/artifacts/rebuild --rps 2`，产出 `rebuild.json`、`har.json`、`mock/playwright-route.js` 与本地 `site/`；需要预览时再人工运行 `python Tool/skill/_pending/site-clone/scripts/site-rebuild.py --crawl Tool/cases/<case>/artifacts/crawl --out Tool/cases/<case>/artifacts/rebuild --serve --port <本地端口> --serve-seconds 5`；3) 仅源码工作区人工运行 `python Tool/skill/_pending/site-clone/scripts/site-diff.py --crawl Tool/cases/<case>/artifacts/crawl --rebuild Tool/cases/<case>/artifacts/rebuild --out Tool/cases/<case>/artifacts/diff.json`，检查 `criteria.route_coverage.missing_rate`、`criteria.pixel.ratio/raw_ratio`、`criteria.dom.min_similarity`、`criteria.resources.http_404/external_links`、`criteria.interactions.passed`、`criteria.data_boundary`；4) 仅源码工作区人工运行 `python Tool/skill/_pending/site-clone/scripts/site-accept.py --case Tool/cases/<case> --json --write`，写 `artifacts/accept.json`，结论为 PASS/PARTIAL/BLOCKED 并透传 `backend_required[]`；5) `python Tool/scripts/preflight.py --fast`。
- 判据：diff.json.criteria.route_coverage.missing_rate<=0.02；静态页 criteria.pixel.max_ratio<=0.01，SPA <=0.03 且保留 raw_ratio；criteria.dom 的 node_ratio/depth_ratio…｜不行就换：crawl 只拿到静态壳 → 加 --engine playwright --allow-host <API host> 重抓并解析 _buildManifest.js/sitemap；像素差集中在字体/抗锯齿 → 固定 --viewport/--dpr 与字体后重拍｜安装态失败：`_pending/` 不可调用是预期边界，不能据此宣称站点复刻能力已自动可用
- 备注：若只在 `work/` 下试跑，可把 `--out`/`--crawl`/`--rebuild`/`--out` 换成 `work/<case>/crawl`、`work/<case>/rebuild`、`work/<case>/diff.json`；但 `site-accept.py --case` 要求案例目录含 `case.json`，否则只会得到 BLOCKED，完整验收仍建议使用 `Tool/cases/<case>`。
