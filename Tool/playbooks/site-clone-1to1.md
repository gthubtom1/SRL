# 网站 1:1 复刻（crawl → rebuild → pixel/DOM/network diff → backend 标注）
- 触发词：1:1 复刻、整站克隆、crawl、像素对比、DOM diff、network diff、后端标注、断网、mock、离线、SaaS、本地版
- 输入（用户提供）：`<URL>`、`<case>`（`Tool/cases/<case>` 案例目录，需含 `case.json` 与 `input/scope.txt`）、允许抓取的路径/host、目标分辨率与本地端口；真实登录与凭据留在用户侧，只接收安全材料。
- 用到的能力（capability id）：`probe:site-crawl` `probe:site-rebuild` `probe:visual-diff` `probe:site-accept` `repo:preflight`
- 入口：读取 `Tool/skill/web-pentest/subskills/site-clone/SKILL.md`。下列 `Tool/` 路径相对注册的源码根，执行前核 `--help`、浏览器/截图依赖与当前 scope。probe 是检索线索，其 reserved/成熟度记录不能代替当前脚本、安装路径和实际调用验证；不从归档 `_pending` 副本执行本流程。
- 步骤：1) `python Tool/skill/web-pentest/subskills/site-clone/scripts/site-crawl.py --url <URL> --out Tool/cases/<case>/artifacts/crawl --max-pages 20 --max-depth 3 --rps 2 --allow-host <ALLOW_HOST>`，核 site-graph.json、pages/、screenshots/、api/ 与覆盖；HTTP 回退没有真实截图，不算视觉验收；2) `python Tool/skill/web-pentest/subskills/site-clone/scripts/site-rebuild.py --crawl Tool/cases/<case>/artifacts/crawl --out Tool/cases/<case>/artifacts/rebuild --rps 2`，产出 rebuild.json、har.json、mock/playwright-route.js 与本地 site/；3) `python Tool/skill/web-pentest/subskills/site-clone/scripts/site-diff.py --crawl Tool/cases/<case>/artifacts/crawl --rebuild Tool/cases/<case>/artifacts/rebuild --out Tool/cases/<case>/artifacts/diff.json`，核 route_coverage、pixel、dom、resources、interactions、data_boundary 六项；4) `python Tool/skill/web-pentest/subskills/site-clone/scripts/site-accept.py --case Tool/cases/<case> --json --write`，写 artifacts/accept.json，保留 PASS/PARTIAL/BLOCKED 与 backend_required[] 原义，结果回 web-pentest 同一 project/version/run。
- 判据：route_coverage.missing_rate<=0.02；pixel.max_ratio 静态页<=0.01、SPA<=0.03 且保留 raw_ratio；DOM、资源、交互与数据边界按子技能 `references/01-criteria.md` 实算。缺截图或交互不能用退出码 0 代替六项验收，HAR/mock 不证明真实后端写入成功。
- 不行就换：静态壳 → 在 scope 内核 Playwright 与 API host 后重抓；字体/抗锯齿差异 → 固定 viewport/DPR/字体后重拍；缺运行依赖 → 报告缺件与当前已证范围。后端需求交协议/Web 主辅链，保留 backend-required，不伪造完成。
- 备注：可在 work/<case> 试跑 crawl/rebuild/diff，但 site-accept 的案例根仍须含 case.json，且证据位置遵守其读取合同；目录存在不等于验收完成。
