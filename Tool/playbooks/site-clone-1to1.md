# 网站 1:1 复刻（crawl → rebuild → pixel/DOM/network diff → backend 标注）
- 触发词：1:1 复刻、整站克隆、crawl、像素对比、DOM diff、network diff、后端标注、断网、mock、离线、SaaS、本地版
- 输入（用户提供）：`<URL>`、`<case>`（`Tool/cases/<case>` 案例目录，需含 `case.json` 与 `input/scope.txt`）、`<登录态 cookie 占位>`、`<允许抓取的路径前缀>`、`<目标分辨率>`、`<本地端口>`；范围由用户提供的 scope 决定，未授权路径按 scope 排除。
- 用到的能力（capability id）：`repo:site-crawl` `repo:site-rebuild` `repo:site-diff` `repo:site-accept` `repo:preflight`
- 步骤：1) `python Tool/skill/site-clone/scripts/site-crawl.py --url <URL> --out Tool/cases/<case>/artifacts/crawl --max-pages 20 --max-depth 3 --rps 2 --allow-host <ALLOW_HOST>` → rc=0，产出 `site-graph.json`、`pages/`、`screenshots/`、`api/`，核对 `coverage.missing_rate<=0.02`；2) `python Tool/skill/site-clone/scripts/site-rebuild.py --crawl Tool/cases/<case>/artifacts/crawl --out Tool/cases/<case>/artifacts/rebuild --rps 2` → rc=0，产出 `rebuild.json`、`har.json`、`mock/playwright-route.js` 与本地 `site/`；需要预览时再跑 `python Tool/skill/site-clone/scripts/site-rebuild.py --crawl Tool/cases/<case>/artifacts/crawl --out Tool/cases/<case>/artifacts/rebuild --serve --port <本地端口> --serve-seconds 5` → rc=0；3) `python Tool/skill/site-clone/scripts/site-diff.py --crawl Tool/cases/<case>/artifacts/crawl --rebuild Tool/cases/<case>/artifacts/rebuild --out Tool/cases/<case>/artifacts/diff.json` → rc=0，检查 `criteria.route_coverage.missing_rate`、`criteria.pixel.ratio/raw_ratio`、`criteria.dom.min_similarity`、`criteria.resources.http_404/external_links`、`criteria.interactions.passed`、`criteria.data_boundary`；4) `python Tool/skill/site-clone/scripts/site-accept.py --case Tool/cases/<case> --json --write` → rc=0，写 `artifacts/accept.json`，结论为 PASS/PARTIAL/BLOCKED 并透传 `backend_required[]`；5) `python Tool/scripts/preflight.py --fast` → rc=0。
- 判据（可机检）：`diff.json.criteria.route_coverage.missing_rate<=0.02`；静态页 `criteria.pixel.max_ratio<=0.01`，SPA `<=0.03` 且保留 `raw_ratio`；`criteria.dom` 的 `node_ratio/depth_ratio/text_similarity/tag_similarity>=0.98`；`criteria.resources.http_404==0` 且白名单外 `external_links==0`；`criteria.interactions.passed>=5`；`criteria.data_boundary.pages` 每页 ∈ recorded-snapshot/local-mock/backend-required；`site-accept` rc=0。
- 失败判据 + 换路：crawl 只拿到静态壳 → 加 `--engine playwright --allow-host <API host>` 重抓并解析 `_buildManifest.js`/sitemap；像素差集中在字体/抗锯齿 → 固定 `--viewport/--dpr` 与字体后重拍；DOM 差来自随机 class → 先规范化再 diff；network 差来自后端签名 → 转 `web-api-sign-reverse`；登录态失效 → 重新取 cookie 并重跑步骤 1；写操作/实时状态 → 只标 `backend-required`，不改写为 PASS。
- 交付物：`Tool/cases/<case>/artifacts/crawl/site-graph.json`、`Tool/cases/<case>/artifacts/rebuild/rebuild.json`、`Tool/cases/<case>/artifacts/rebuild/har.json`、`Tool/cases/<case>/artifacts/rebuild/mock/playwright-route.js`、`Tool/cases/<case>/artifacts/diff.json`、`Tool/cases/<case>/artifacts/accept.json`、`report.md`。
- 备注：若只在 `work/` 下试跑，可把 `--out`/`--crawl`/`--rebuild`/`--out` 换成 `work/<case>/crawl`、`work/<case>/rebuild`、`work/<case>/diff.json`；但 `site-accept.py --case` 要求案例目录含 `case.json`，否则只会得到 BLOCKED，完整验收仍建议使用 `Tool/cases/<case>`。
