# 网站 1:1 复刻（crawl → rebuild → pixel/DOM/network diff → backend 标注）
- 触发词：1:1 复刻、整站克隆、crawl、像素对比、DOM diff、network diff、后端标注、断网、mock、离线
- 输入（用户提供）：`<url>`、`<登录态 cookie 占位>`、`<允许抓取的路径前缀>`、`<目标分辨率>`、`<本地端口>`；范围由用户提供的 scope 决定，未授权路径按 scope 排除。
- 用到的能力（capability id）：`tool:katana` `tool:ffuf` `tool:nuclei` `mcp:playwright` `repo:web-check` `repo:pcap-summary` `repo:web-repro` `repo:web-accept` `repo:case_state` `repo:seep-start`
- 步骤：1) `python Tool/scripts/seep-start.py --domain web-pentest --case <case> --target <URL>` → rc=0，生成 scope 与 evidence 目录；2) 用 katana/ffuf 的清单落 `work/<case>/urls.txt`，再用 `python Tool/skill/web-pentest/scripts/web-check.py --url <URL> --max-paths 200 --rate 2 --out work/<case>/target.json` → rc=0 或 3，记录状态码、头、重定向与 robots；3) 本地重建站点起在 `<LOCAL_PORT>`，`python Tool/skill/web-pentest/scripts/web-check.py --url http://127.0.0.1:<LOCAL_PORT> --max-paths 200 --out work/<case>/local.json` → rc=0，逐条对照 target/local 的 path 集合；4) 网络 diff：`python Tool/scripts/pcap-summary.py --file <target.pcap> --out work/<case>/net-target --json` 与 `--file <local.pcap> --out work/<case>/net-local --json` 均 rc=0，差异写入 `work/<case>/net-diff.json`；5) DOM/像素 diff：用 `js-reverse_*` 或 playwright 对同一路径取 DOM 快照与截图，diff 落 `work/<case>/dom-diff.json` 与 `pixel-diff.json`，再用 `python Tool/scripts/case_state.py prove --case work/<case> --id D1 --evidence work/<case>/dom-diff.json` → rc=0；6) backend 标注：对每个 XHR/Fetch 在 `work/<case>/backend-map.json` 标 `static|mock|real-api|unknown`，用 `python Tool/skill/apkseep/scripts/probe_api.py --base <API_BASE> --path <path>` → rc=0 或 2 取证；7) `python Tool/skill/web-pentest/scripts/web-accept.py --case <case> --json` → rc=0，最后 `python Tool/scripts/preflight.py --fast` → rc=0。
- 判据（可机检）：target/local 的 path 集合差集为空或每项有 `scope-excluded` 原因；`dom-diff.json.diff_ratio<=0.01`；`pixel-diff.json.changed_pixels<=0.01`；`net-diff.json` 每条差异有 `kind`；`backend-map.json` 无 `unknown` 未解释项；`web-accept` rc=0。
- 失败判据 + 换路：crawl 只拿到静态壳 → 改 `js-reverse` 监听 XHR 后重抓；像素差集中在字体/抗锯齿 → 固定字体与 DPR 后重拍；DOM 差来自随机 class → 先规范化再 diff；network 差来自后端签名 → 转 `web-api-sign-reverse`；登录态失效 → 重新取 cookie 并重跑步骤 2。
- 交付物：`work/<case>/site/`、`urls.txt`、`target.json`、`local.json`、`net-diff.json`、`dom-diff.json`、`pixel-diff.json`、`backend-map.json`、`report.md`。
