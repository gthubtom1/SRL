# 06 失败判据速查（pwn-crypto）

> 配套 `Tool/skill/pwn-crypto/references/02-failure-criteria.md`。
> 一页纸版本：看到现象 → 判定 → 改走哪条 → 代价。用于现场止损，不替代完整报告。

## 入口信号

- 同一路线已经试了 2 次仍无进展；
- 偏移/泄漏/回代有一个对不上；
- 平台或库版本与假设不一致；
- 成功率在 50%–80% 之间摇摆。

## 失败判据表

| 现象 | 判定 | 改走哪条 | 代价 |
|---|---|---|---|
| objdump 与 probe 偏移不一致 | 偏移不可信 | 统一编译选项/帧指针，再 gdb 复核 | 低 |
| 崩溃但 `$rip` 不是 cyclic 值 | 没控到 saved RIP | 查 canary/SEH/函数指针，或转格式化串/堆 | 中 |
| `checksec` 全绿且无泄漏 | 栈/GOT 双封 | 格式化串（先验 `%n`）/堆/逻辑/密码学 | 高 |
| `%n` 探针后变量仍为 0 | 运行库不写 `%n` | 只保留任意读；写路线转堆/逻辑/换平台 | 低 |
| `%s` 直接崩 | 地址不可读或参数序号错 | 先用 `%p`/已知全局变量校准序号 | 低 |
| `malloc` 不返回 target | 堆布局/版本不符 | 定 glibc；2.32+ 编码 safe-linking；2.34+ 换 IO/exit | 高 |
| `free` 报 corruption | 元数据被破坏或构造错 | 复核 size/prev_size/key/对齐；先小步验证重叠 | 中 |
| 整数回绕但程序正常退出 | 没有真实越界 | 打印 `_msize/写入长度`；加大写入；看堆破坏状态码 | 中 |
| seccomp 无 open/read/write | 外带路径被封 | SROP/栈迁移/`openat`+`sendfile`；否则如实写无法读出 | 中 |
| 泄漏低 12 位对不上 libc | libc 版本错 | libc-database/远程泄漏；或 ret2csu/程序自带函数 | 中 |
| `pow(m,e,n)!=c` | RSA 假设不成立 | 查填充/同一 m/模数互质；换共模/广播/Wiener/Fermat | 低 |
| CRT 开方不精确 | 组数不足或消息不同 | 增加互质模数；确认 `m^e<M` | 低 |
| PRNG 下一输出不一致 | 输出不连续/额外消耗 | 记录随机数调用序列；只用连续 624 个 32-bit | 中 |
| CBC 目标字节没变 | 块索引/IV 改错 | 用 `crypto-verify --cbc` 验证 `before^after==xor` | 低 |
| 本地 6–8/10 成功 | 栈未对齐/竞态 | 加 `ret` 对齐、固定环境，重跑 ≥10 次 | 低 |
| 远程与本地不一致 | 环境差异未解释 | 远程泄漏校验 + 同版本 libc 复现 | 高 |
| PE 上找不到 GOT/RELRO | 平台语义混用 | 改用导入表/CFG/SecurityCookie/`VirtualProtect` | 中 |

## 停机规则

1. 同一路径连续 3 轮无进展 → 换路线；
2. 同一目标同类动态尝试最多 2 次，第 2 次失败必须停下汇报；
3. 任何“成功”如果没有命令、退出码、原始输出/回代等式，一律降级为“疑似”；
4. 换路线后要重新建立证据链，不能把旧结论迁到新路线。

## 失败也要交付

- 已排除路线与依据（命令 + 输出片段 + 状态码）；
- 当前停在哪条判据；
- 再试一次的代价（时间/新工具/新样本）；
- 平台差异说明（PE vs ELF、UCRT vs glibc、Windows 堆 vs glibc 堆）。

## 确认判据（本文用对了的样子）

- 报告里能一眼看出“哪条判据失败 → 改走哪条 → 代价多少”；
- 失败路线没有被写成“环境问题”一笔带过；
- 没有用一次偶然成功冒充稳定。

## 边界

- 失败判据是止损工具，不是“放弃理由”；换路线后仍按 `01-criteria.md` 重建证据。
- 环境缺失（无 Linux、无同版本 libc、无 gdb）应写 `blocked_at`，不要伪造成功。
