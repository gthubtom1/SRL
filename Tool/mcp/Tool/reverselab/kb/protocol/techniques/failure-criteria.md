# 失败判据（protocol board）：看到即降级

> 入口信号：同一条路连续 2 次没有新信息；服务端行为与模型不一致；出现风控/越权。
> 深水区（完整版）：`Tool/skill/protocol-plugin/references/02-failure-criteria.md`。
> 本页是随手查的版本：现象 → 判定 → 改走哪条 → 代价。

## 0. 三种"停"

| 类型 | 触发 | 动作 |
|---|---|---|
| 硬停 | 越权读、风控封禁、需要他人凭据 | 立刻停，留证，不换账号/IP 绕过 |
| 软停 | 同一手段连续 2 次无新信息 | 换观测层：网络 → 进程内 → 静态 |
| 降档 | 只有 1–2 帧样本、单次现象 | 结论改成"疑似"，不写"确认" |

## 1. 失败判据表

| 现象 | 判定 | 改走哪条 | 代价 |
|---|---|---|---|
| 两次抓包 `tcp.len=0` / 全是 `data` | 抓包点错，或 TLS 无 keylog | `tshark -D` 重选网卡；容器抓 veth；设 `SSLKEYLOGFILE` | 低（10 min） |
| 只有 TLS 记录层 | 无明文 | keylog → 代理装 CA → 进程内 hook → 静态反推 | 中（pinning/mTLS 会挡） |
| 明文在但 tshark 只显示 `data` | dissector 不认识私有协议 | 用 `pcap-summary.py --extract` 取流 + 自建字段表 | 低 |
| 3 帧以上定不下长度覆盖 | 样本太单一 / 字段不含长度 | 制造不同长度帧再拟合；仍不行按定界符/type 定长 | 中（构造流量需靶场） |
| 改长度/校验后**无任何响应** | 服务端静默丢弃等超时，或被中间件吞 | 两端抓包确认到达；按"静默丢弃"记为负例 | 中（易误判成网络问题） |
| 原样重放 OK，改 1 字段即拒 | 签名/nonce/时间窗/设备指纹/风控 | 逐字段回显实验定位签名覆盖；复现不了只报"部分复刻" | 高（常需转 js/ida） |
| 重放响应与基线不同且无法解释 | 会话被踢 / 业务状态变了 / AB 实验 | 先做 3 次基线方差；换新会话；列可变字段 | 低（多半是状态问题） |
| 一次性 token，第二次 401 | 防重放/一次性 nonce | 把"取 token → 发请求"串成两步；不能自动化就人工演示 | 中（脚本要重写） |
| WS JSON 半截/解析失败 | 消息跨 TCP 段 / permessage-deflate / 控制帧 | 按 FIN/opcode/长度重组；先 inflate 再 parse | 低（解析器问题） |
| h2 请求配错响应 | 多路复用 + HPACK | 按 `streamid` 分组，同流按帧序；看 END_HEADERS/END_STREAM | 中（要完整 h2 解析） |
| protobuf 字段号跳跃/乱码 | 无 schema / 字段号≠业务 id / 前面还有压缩 | `protoc --decode_raw` 看结构；先解压再解 | 中（错一层全错） |
| 熵 > 7.5 但找不到 nonce/IV | 流加密隐式计数，或整段封装 | 找计数器与密文长度关系；两条已知明文 XOR 判族；不行转进程内 | 高（盲猜几乎不可能） |
| 429 / 验证码 / 封禁页 | 触发风控 | 立即停，留证，不绕过 | 高（影响授权范围） |
| 需要客户端证书 | mTLS | 从授权方取证书；否则只做单向可见分析并写"未解" | 高（通常无法绕过） |
| 时间戳全 0 / 乱序 | pcapng SPB、时钟不同步、多网卡合并 | `pcap-summary.py` 看 format/first_ts；`editcap -F pcap` 转换 | 低（工具问题） |
| 同端口多连接被合并 | 五元组相同但连接不同（端口复用） | 按 `tcp.stream` 分会话 | 低（重跑即可） |
| 换台机器跑不出同样结果 | 依赖绝对路径/私有样本/时区 | `__file__` 推导路径；样本入案例 `input/`；时间用 UTC epoch | 低（但会让"可复跑"判据直接失败） |
| 换会话 id 读到别人数据 | **越权** | 立即停，保留证据，按授权流程上报 | 红线 |

## 2. 三条替代路线

| 路线 | 何时用 | 入口 |
|---|---|---|
| 进程内取明文 | 网络层加密且无 keylog | `frida-trace -m SSL_write -m SSL_read`、LD_PRELOAD、调试器断点 |
| 静态反推格式 | 客户端二进制在手 | `ida-reverse` / `softseep`：序列化函数、字段写入顺序、校验计算 |
| 只做可见面报告 | 时间/授权不够 | 会话表 + 字段表（标疑似）+ 状态图（标 INFERRED）+ 卡点清单 |

## 3. 记账模板

```text
已花：抓包 2 轮 / 分帧 1 轮 / 重放 3 次
卡在：签名覆盖范围（字段 f7 改动即 401）
改走：客户端 JS 取签名函数（js-reverse）
风险：生产环境，已停止重放，未触发封禁
```

## 4. 边界

- 风控/越权相关一律硬停；"换账号绕过"不属于本域方法。
- 失败判据不是免责声明：写"部分复刻"时仍要给已确认部分 + 可复跑命令。
- 本页与 `references/02-failure-criteria.md` 冲突时，以 references 为准（那份是门禁口径）。
