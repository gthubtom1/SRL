## 写作纪律

1. 一条日志只写一次现场：目标、命令、原始输出片段、结论、边界。
2. 结论必须能落到判据（`references/0*-criteria.md`），不写"感觉"。
3. 同一主题满 3 篇 → 沉淀为 `techniques/` 一篇，日志只留链接。
