# 客户端许可与激活校验

先回答四问：权威在本地、服务端还是硬件；能本地满足验证还是只转发；是否有当前构建确有的测试入口；业务功能与校验有哪些真实依赖。复用 [许可深度参考](../../references/license-validation.md)、[补丁工程](../../references/09-patch-engineering.md)、[完整性](../exe-reverse/references/integrity-checks.md) 与 [网络激活](../exe-reverse/references/network-activated-licensing.md)。案例地址、时序和补丁数量只属于案例，不当全局阈值。

项目登记/接续见 [router](../../../seep-router/SKILL.md) 第 5 步；测绘用 `Tool/playbooks/reverse-survey.md`，不再调用旧裸阶段名或已取消快捷命令。已有 case 的 gate 可核专业可行性，但不是所有结构审计必须先建旧阶段 case；当前项目账与实际问题决定需要哪些阶段。

## 输入、保护与权威

固定目标版本、SHA256、运行时、签名/保护、所需功能与交付形式，保留原件。PE/ELF/Mach-O 按对应格式，.NET 核 IL/ReadyToRun/NativeAOT，Electron 核 asar/原生模块，JVM 核字节码/native，Python 冻结核解释器版本。字符串、静态导入缺失、异常高熵都不能单独证明加密壳或权威归属。

| 路线 | 前提与最小验证 | 不可推出 |
|---|---|---|
| 本地校验 | 代码/数据流与合成正反许可证明本地决策，核初始化/状态消费者 | 看到 UI 状态字不等于所有功能受其控制 |
| 服务端/混合 | 协议/代码和用户侧测试结果说明票据、心跳或业务仍依赖服务端 | 本地分支 patch 不会创造服务端能力或有效签名 |
| 硬件绑定 | 核具体硬件参与身份、密钥/运算还是只读标识 | 模拟机器码不等于替代加密狗运算 |
| 载荷独立性 | 已取得安全载荷，核入口、初始化、导入、重定位、配置、二次验证及功能 | 空导出表/只有 kernel32 不证明无校验、无回连或独立可用 |

真实账号、卡密、Token、Salt、Key、私钥由用户自己操作，不进入 Agent 参数/日志/抓包/内存转储；不先读后打码/散列。实际登录/授权由用户侧完成，只交安全结构与判定。无安全观测通道则保留限制。

## 动态与保护分支

运行客户目标须已有运行确认与合适环境。先建未修改基线，插桩行为单独对照；崩溃可能是缺依赖、参数非法、跳过初始化、时序或完整性，不能“改一个字符存活四秒”就排除自保护。两次同形失败重判并换层，不无限注入。

PE 壳按 [unpack-pe](../unpack-pe/SKILL.md) 与 [unpack-loop](../../../unpack-loop/SKILL.md)，Android 的 DEX/SO 按 [apkseep](../../../apkseep/SKILL.md)，不套一个 OEP 流程处理所有平台。VMP/逐页解密允许局部分析结果，缺关键代码时明确未完成。

修改本地分支/状态需核返回类型、调用约定、初始化、心跳回写与受影响功能。代理 DLL/注入器/重包仅在适合目标且约定交付需要时选；写入只在目标副本/获准进程，补丁清单记录原字节、位置、语义、副作用与回滚。不要批量扫所有字符串等长替换；合法字符串还要符合对象布局与生命周期。

## 回放、中继与端点

默认用合成夹具或用户侧安全会话。端点变更只作用于目标进程支持的启动参数、进程环境或局部 hook；不提供改整机 IP/路由/DNS/hosts、全局代理、时钟、驱动、服务或信任根的执行步骤。没有等价局部通道就保留阻断，不把 VM 当自动扩大操作权限的例外。

金样回放只验证特定输入/状态下旧响应是否仍有效；需核 nonce、请求关联、时间窗、签名与业务语义。多次令牌变化/体长恒定只是绑定候选，不能单独证明密码学绑定，也不能由一次静默退出判定原因。新请求与错 nonce/过期等反例区分缓存或格式错误。

透明中继保持上游请求/响应不变，只证明上游授权仍参与，不能声称离线伪造。流实现需重组、长度/分块/keep-alive、错误与超时；不记录包含秘密的原始会话。无安全转发通道时只交协议结构分析。端点缺失或服务器拒绝不以拒绝服务当成功。

需要调用实际 Seep MCP 时先核连接与 schema，示例为参数形态：

```text
seep_packer_detect(binary_path="<当前目标绝对路径>")
seep_r2_cmd(binary_path="<当前目标绝对路径>", command="iR", analyze=false)
seep_r2_decompile(binary_path="<当前目标绝对路径>", target="<已核函数地址>")
```

协议请求若涉及真实凭据不直接用会回显全头/体的工具；不因工具提供 headers/cookies 字段就传用户秘密。

## 载荷与功能验证

内存/下载响应中的 MZ 仅是候选，须核 PE/其他格式边界、完整区域、映射和依赖；不以固定“本体+余量”扩读内存。载荷可能缺初始化上下文、动态解析导入、配置、回连和校验。先静态分析，需运行则在已有许可下验证目标功能及正反输入；不靠进程名相同/主窗口出现就称完整可用。

正例：本地合成许可路径的修改在新进程中完成约定功能，错误条件仍可解释，相关功能无回归、原件未改。反例：许可弹窗消失但导出按钮仍被服务器拒绝，或 DLL 能解析却无正常初始化；报告局部结果，不能称成品。

交付按用户目标：审计报告含权威、保护、代码/协议证据、反例、未知与加固建议；修改任务另附可复现工装、补丁清单、原件/产物身份、功能回归与回滚。不要求改系统时间测试试用期，可使用合成测试时钟/目标进程局部观测并注明条件；不得把两个心跳存活等同所有功能稳定。

## 追版与跨域返回

版本迁移读 [multiver-aob](../multiver-aob/SKILL.md)，配合 `Tool/skill/softseep/scripts/version-migrate.py --help` 核当前版本账命令。唯一 AOB 命中仍须当前版本语义/原字节和功能验证，缺失/歧义转人工，不把旧偏移盲贴。

协议请 protocol-plugin，算法请 pwn-crypto，APK 请 apkseep；交接带输入哈希、符号/流位置、已证/未知、具体问题与安全输出，返回同一 project/version/run。停手报告写清恢复条件，缺服务器、设备、代码或安全凭据通道可构成真实上限，不能用“必须继续做成品”掩盖失败。
