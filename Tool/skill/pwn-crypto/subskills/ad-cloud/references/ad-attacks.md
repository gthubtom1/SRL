# AD 属性、图谱与暴露面复核

入口：[SKILL](../SKILL.md)，统一门槛见 [01-criteria](01-criteria.md)。本页替代旧攻击命令速查，保留风险判断所需条件。真实认证由用户侧完成，只提供安全属性/决策/遥测；不在 Agent 中设置密码变量、导出凭据、对时、发起 relay 或改系统/目录对象。

## 目录与图谱

先核域/林/对象身份、采集时点、主体别名、组嵌套、ACL 继承/deny 与信任边界。目录 DN 不应由“域名切成两段”猜出；使用用户提供的 naming context/实际目录配置。adminCount、SPN、委派标志或高权组名称都是定位线索，需核当前有效成员与权限，不能只看名字。

| 线索 | 核验条件 | 结论上限 |
|---|---|---|
| BloodHound 到高权目标的路径 | 采集器/schema/版本、每条边的类型/来源/时间、原始属性或有效 ACL、身份/信任与条件限制 | 已支持的配置路径 candidate；图中路径不是可执行攻击见证 |
| SPN 与预认证属性 | 账号类型/启用状态、服务归属、加密/预认证策略、已有 KDC 事件 | 确认相应配置风险；不请求可破解响应或验证口令 |
| GenericAll/WriteDACL/WriteOwner/AddMember 等 | 精确对象/属性、继承/deny、组成员、目标保护与采集后变更 | 有效权限配置事实；不实际修改来证明可利用 |
| Sessions/本地管理员关系 | 会话来源、过期/复用、登录标识和权限范围 | 该采集时刻可见关系；不证明凭据可导出或可在另一主机复用 |
| ADCS/委派 | 模板/CA/映射及 SPN/有效 ACL，独立技术条件 | 分别见 [Kerberos/ADCS](kerberos-and-adcs.md)、[委派](05-delegation-and-rbcd.md)，不强求 TGT/私钥作为 confirmed |

不运行全量采集寻找“下一跳凭据”；已有图谱/属性必须在用户侧过滤，原 zip/日志可能含秘密时不先导入再脱敏。未发现路径可以按实际覆盖完成，不能为有结论扩展目标或身份。

## 公网与接入面

只在当前 scope 内使用既有安全协商信息或公开、能限定字段的元信息。端口/页面身份与实际应用行为分开；不做用户名枚举、默认口令尝试、强制认证、投毒或 CVE 攻击升级。

| 信息面 | 可核字段/条件 | 反例与边界 |
|---|---|---|
| SMB/NTLM | dialect、signing 要求、type 2 的公开目标信息与来源时间 | 工具可能发送 session setup/匿名或 guest 请求，不能一概称“不认证”；type 2 不证明 relay 或登录成功，不收集 type 3/认证响应 |
| LDAP rootDSE | namingContexts、dnsHostName、协议/控制支持及返回状态 | rootDSE 可读不等于目录对象可读/可写；不能为证据关闭 TLS 验证或改系统信任根 |
| Kerberos | 已有 KDC/策略元信息、预认证/账号状态和错误类别 | PREAUTH_REQUIRED、账号错误与版本/策略有关；不以发送 AS-REQ 获取可破解响应为“只读探测” |
| VPN/邮件前端 | 公共页面厂商/版本线索与独立静态资产、公开 metadata | 通用 Cookie 名/200/403 不能唯一指认厂商或补丁状态；不读取会话 Cookie 值 |
| Okta/Entra/联邦 | 用户提供的公开 issuer/tenant/endpoints、资产归属、联邦配置 | 跨租户/第三方跳转不能自动跟随；UI 因素图标不证明 MFA 策略，失败码不唯一证明账号状态 |

公开信息 confirmed 应写“该字段/端点可见”，不必为升级 confirmed 取得账号/票据或执行远程命令。认证/权限由用户侧正常流程核验，仅返回主体别名、目标、动作、结果类别与关联标识；缺材料则 unknown。

## 交付与停手

每条风险保留原始安全字段、对象/版本/时点、路径前提、支持/反证和未覆盖范围。只读检查也须有范围/速率，遇认证预算、告警、输出秘密或同形失败两次停止；不换身份/服务继续试。系统时间偏差只记录，不执行 chrony/NTP/Windows 对时或变更网络。

正例：目录 ACL 与图谱边在同一采集时点相符，可确认该权限配置。反例：最短路径有边但原属性已变、权限被 deny 或身份不匹配，应撤回路径结论，不能补写攻击成功。
