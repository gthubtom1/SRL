# 认证与横向行为：既有遥测复核

入口：[SKILL](../SKILL.md)。本页调查已有事件、权限配置和用户侧测试结果，不发起 PtH/relay/远程执行，不建立或删除服务、计划任务、账号、对象或会话，不收取 hash/票据/口令。历史原件为 `Tool/skill/_pending/ad-cloud/references/06-lateral-movement.md`，其中命令、动作分级和工具行为断言不作为当前执行步骤。

## 分开认证、授权与执行

认证成功说明某身份在一个协议端点被接受；授权决定具体动作；目标侧执行/访问需要独立记录。Pwn3d!/SUCCEED、ReturnValue=0、会话建立或无异常都不能单独证明预期命令执行。合法管理行为也产生同类事件，恶意归因仍需上下文。

每条关联保留：源/目标主机别名、主体别名、协议/服务、时间与误差、LogonId/会话 ID、目标进程标识/开始时间、工具/版本及安全动作描述。用户侧执行只返回非秘密结果，不提供凭据、完整命令行或可能包含秘密的输出全文。

## 协议与事件线索

| 观察面 | 既有证据与技术条件 | 不能单独证明什么 |
|---|---|---|
| SMB/NTLM | 目标签名要求、会话/共享授权记录，4624 类型 3；4776 在实际验证凭据的机器，可能是 DC | signing 可见不代表所有访问安全；4776 不必出现在目标，认证/READ/WRITE 标记不等于文件读取/写入成功 |
| LDAP/LDAPS | LDAP signing、TLS/EPA/通道绑定的实际强制条件；目录读/变更审计按对象/属性关联 | SMB signing 不决定 LDAP；TLS 存在不自动证明通道绑定强制，认证不等于对象可改 |
| WinRM | 对应会话/Operational 日志、认证方式、消息签名/加密及目标进程记录 | HTTP 认证成功不代表命令执行；NTLM relay 的成功握手也不能替代会话密钥/消息保护条件 |
| WMI | 目标 WMI 活动及相关进程创建、主体/会话与时间 | ReturnValue=0 或父进程 WmiPrvSE.exe 单项不证明远程恶意执行 |
| Task Scheduler | 4698 创建、4699 删除、4700 启用、4701 禁用、4702 更新，结合 TaskScheduler Operational 与进程记录 | 创建/启用不等于任务运行；不能把 4700/4702 当运行/结束事件 |
| DCOM | COM 激活、可用对象/版本、会话与目标进程/行为记录 | mmc.exe/dllhost.exe 单个父进程不能唯一归因 DCOM 或攻击 |
| 委派/RBCD | 已有目录属性/5136、KDC 4769 与服务访问 | 目录变更或票据请求不证明访问成功；见 [委派参考](05-delegation-and-rbcd.md) |
| MSSQL/RDP | 用户侧查询/会话结果、数据库授权或 RDP 登录/会话日志 | 登录成功不证明 sysadmin、shell 或跨资源授权；截图不能替代来源/会话证据 |

工具家族、版本和执行方法影响是否创建服务/任务/临时文件；不能一概把 wmiexec 归为 RemCom 服务。必须按既有记录核实际机制，不为比较工具而重放动作。

## 证据强度与失败

| 情况 | 合理结论 | 下一步 |
|---|---|---|
| 客户端称成功，缺目标记录 | 客户端观察已记录，目标行为未知 | 补用户侧筛选的已有会话/进程/审计，缺覆盖则保留 unknown |
| 目标有进程，缺源/主体关联 | 该进程存在/启动可确认，远程起因 candidate | 核时间窗、登录标识、父子关系与独立遥测，排除正常管理 |
| 权限配置允许，但用户侧被拒 | 配置/实际结果有差异 | 核服务策略、身份、版本及时间，不改防火墙/服务/认证机制 |
| 没有事件或有缺口 | 本采集面未观察到/不完整 | 核审计、channel、过滤与留存，不删除或重建日志，不把缺失写成未发生 |
| 认证失败/锁定风险、同形两次失败 | 当前验证路线停止 | 记录错误与恢复条件，不换账号/工具继续 |

正例：既有管理工单中的测试标记、目标进程记录和会话 LogonId 一致，可确认那次目标操作；是否异常另判。反例：只有 SUCCEED 或一个 4624，不能写“已横向执行”。
