# 失败、未知与恢复条件

入口：[SKILL](../SKILL.md)，判据见 [01-criteria](01-criteria.md)。失败后只换安全证据面；不得改系统、换账号/工具规避预算，或转向秘密采集。

| 现象 | 当前可判定内容 | 安全下一步 / 保留未知 |
|---|---|---|
| 用户侧返回 KRB_AP_ERR_SKEW | 当前认证受时钟条件影响 | 只读记录时间源、采集时刻和偏差范围，容忍值按实际策略核；不执行对时。用户自行处理环境后返回新的安全结果，否则 blocked |
| 锁定/认证失败、预算到限 | 暂停该认证路线 | 保留错误类别、主体别名和时间，用户核账号状态；不换账号/协议/来源继续试 |
| 只有 SPN/预认证属性或旧 roast 结果 | 可确认相应配置/历史事件，口令可恢复性未知 | 核版本、账号策略和既有遥测；不索取 hash、增强字典、破解或复用票据 |
| ADCS scanner 标 vulnerable，但无 Enroll/需审批/SAN 受限 | 所述路径的关键前提不成立或未知 | 核安全模板/CA 配置及有效权限；不改模板、ACL、UPN 或换模板发证补验收 |
| 用户侧证书认证失败 | 该身份/证书/服务在本次条件下未成功 | 仅核公有 EKU/SAN/链、信任/映射、补丁和时间条件；不收取 PFX/私钥/TGT，不以重试代替原因 |
| signing/EPA/通道绑定/RPC 加密要求存在 | 对应协议路径受限 | 核具体端点/协议与强制条件，记录覆盖；不关闭控制、强制认证或换目标 relay |
| 委派属性存在但无服务验证 | 配置可确认，身份冒用/访问仍未知 | 核 SPN、有效 ACL、账号限制与独立日志；不捕获/导入票据，不写 RBCD |
| can-i=no 或无法取得决策 | 仅此主体/资源/namespace/时刻被拒或未知 | 核绑定/条件和用户侧安全结果；不转真实 Secret/CI 凭据、不换 SA 扩权 |
| can-i=yes，但 admission/Quota/运行时拒绝 | 授权与执行阶段结果不同 | 记录拒绝阶段和配置；不创建特权 Pod、改标签或禁用策略。所述路径受阻不证明所有路径安全 |
| privileged/hostPath 存在但没有节点证据 | 配置风险候选，逃逸未证实 | 核已有节点/runtime 审计与挂载来源；不挂载、nsenter 或读取宿主文件/凭据 |
| 用户侧 ExpiredToken/InvalidClientTokenId | 当前认证链失败 | 用户侧核认证状态，只返回安全结果；不找新凭据来源、不读取元数据 Token |
| IAM 文本 allow，用户侧 AccessDenied | 模型/上下文可能缺层，或目标动作受限 | 核 action/resource/条件及 boundary/SCP/资源/会话策略；不修改权限、创建 key 或切换区域规避限制 |
| 日志无 Kerberos 事件或 RecordId 断档 | 当前采集面不完整/没有观察到 | 核主机角色、channel、审计与时间窗、滚动/转发/过滤；补用户侧安全日志，不清除/开启审计设置来重现 |
| 只有 SUCCEED/ReturnValue=0/HTTP 200 | 工具请求或握手结果，业务效果未知 | 补已有目标会话/进程/审计与非秘密输出；不执行远程命令、建服务/任务补证据 |
| 输出包含或即将包含秘密 | 当前通道不适用 | 在采集前限制字段，由用户侧筛选；无法安全观察即 blocked。事后删除/打码不是替代 |
| 同形失败两次或无新证据 | 当前路线应停止 | 重判前提、记录反证与所缺材料，或交付有边界的报告，不升级动作 |

“只读”不代表无副作用：认证失败、全量目录枚举、远程注册表/工具自动服务启动可能造成影响；执行者和工具真实行为必须核实。风险评估可以以无发现、反例或未知完成，不要求制造一次攻击成功。

历史失败表为 `Tool/skill/_pending/ad-cloud/references/02-failure-criteria.md`；其中系统对时、转凭据来源、改对象或攻击升级步骤不作为当前执行指引。结论与恢复条件返回同一 project/version/run。
