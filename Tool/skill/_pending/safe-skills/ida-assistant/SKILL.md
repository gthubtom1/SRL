# IDA 会话辅助

连接、许可、真实 schema、目标身份与分析流程以 `Tool/skill/_pending/ida-reverse/SKILL.md` 为准；沿用同一项目/版本/run。

1. 使用当前宿主已注册的 IDA 工具，发现真实工具名/输入 schema，核对绑定资产后定向查询；不假定 `idapro_*` 前缀、72 个工具或某台旧机器的 OpenCode schema 故障仍成立。
2. 旧 `scripts/start.ps1`、`scripts/open.ps1` 是特定环境辅助材料，含进程终止/数据库清理行为；不作为默认启动或“绕过 MCP 校验”的方案。确需用时先核当前脚本副作用及目标副本，不能杀无关会话或删除用户数据库。
3. 连接失败先区分宿主注册、协议握手、插件、许可、文件锁、自动分析进度；超时只说明本次未完成，不能固定等几秒就断言死锁，也不无限重试。
4. 先概览再读相关函数/xrefs/数据流；伪代码与反汇编互证。只在工作副本保存注释/类型/重命名，并记录返回主域的证据和未知。
5. 进制转换可用可靠本地工具并回代，不强制为了数字转换调用商业反编译器。缺专有能力时参考 r2/静态替代，无法等价回答则标明限制。
