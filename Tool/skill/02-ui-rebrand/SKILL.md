# 02 · 改 UI / 换品牌 / 去作者信息

> **前提**：`01-gate-bypass` 已交付，且"双击 → 主界面 → 功能全通"已通过。
> **本阶段不改业务逻辑、不改授权判定**，只改"看起来是谁的软件"。

---

## 1. 先清点（不写一行代码，先出清单）

| 清单 | 拿到什么 |
|---|---|
| 页面清单 | 主界面 / 皮肤库 / 应用 / 导出 / 关于 / 设置…（逐页截图） |
| 控件清单 | 每页的按钮/列表/输入框/状态栏位置与尺寸 |
| 文案清单 | 标题、按钮文字、提示语、错误信息、版本号 |
| 品牌资产 | 图标、Logo、启动画面、关于页作者信息、二维码、官网/群链接、更新地址 |
| 技术栈 | 自绘 UI（如 CXWidgetUI/CXShape）/ Qt / Tk / Web / Android 布局 |

产物：`work/<task>/ui-inventory.md`（后续改造的对照基准）。

---

## 2. 替换策略（按技术栈选）

| 栈 | 做法 |
|---|---|
| 自绘 UI（Direct2D/GDI/Qt 自绘） | 改资源表 + 字符串表 + 布局常量；色板/圆角/字体统一替换 |
| Qt / Win32 标准控件 | 改 `.ui`/资源脚本或消息钩子；字号与主题集中替换 |
| Web / Electron | 改 asar 内 HTML/CSS/JS 与 `package.json` 品牌字段 |
| Android | 改 `res/`、`strings.xml`、图标、`AndroidManifest` 应用名；重签名 |
| Tk / Python 打包 | 改源码中 `title()/Label` 文案与配色，再重新打包 |

**原则**：优先"替换资源与文案"，其次"改布局常量"，**最后**才重绘控件；每步都能回滚。

---

## 3. 去品牌（逐项勾掉）

- 原作者名 / 昵称 / QQ / 微信 / 邮箱 / 群号
- 推广二维码、赞助入口、跳转链接
- 更新地址 / 官网 / 公告接口（改成你自己的或直接移除）
- 关于页版权行、版本号里的原始作者标记
- 残留字符串（用 `strings` 或 `seep_r2_strings` 复查一遍）

---

## 4. 回归（必须全绿才算完成）

1. 功能面：01 阶段的 FEATURES 清单逐项复测，不退化
2. 授权面：01 的旁路仍然有效（不因改 UI 失效）
3. 稳定性：连续启动 3 次不崩、无新增弹窗
4. 回滚：保留 01 产物副本，改坏可一键还原

---

## 5. 交付

- 改造后的产物（与原版同形态：EXE / APK / 安装包）
- `ui-changes.md`：改了什么（文件/资源/文案对照）
- 前后截图对照（每页各一张）
- 回滚脚本

---

## 6. 禁止项

- ❌ 改 UI 时顺手改业务逻辑或授权判定（越界到 03）
- ❌ 只改窗口标题就算"换品牌"
- ❌ 用"重新写一个界面"替代改造（那是 01 明令禁止的复刻体）
