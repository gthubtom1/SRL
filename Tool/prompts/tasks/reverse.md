逆向 <目标>，旁路验证它的门禁，交付一个**独立可分发**的可用产物：
单文件 EXE，不依赖原版、不依赖 Python 环境，功能与原版等价，全程无卡密/授权提示。
原版跑不起来 / 逻辑在 VM 里 → 直接走"独立重实现"，不要在让原版跑上死磕。

产物必须留一个授权扩展点：`--license off|required`（默认 off）+ `check_license()` + 你的 keygen，
这样我以后分发时能自己接卡密页；验收要在**没有原版的干净目录**里双击跑通。

不许交复刻体 / .cmd / .py / 需要原版才能跑的 launcher；不许以"壳阻塞"结案；不许问"要不要继续"。
先报 RUNTIME / GATE / DELIVERY 三行等我确认，然后一路做到能双击可用、可分发为止。
