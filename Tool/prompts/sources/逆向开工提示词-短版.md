```text

双击启动 → 主界面出现（游戏辅助类：宿主内菜单出现）→ 全部功能正常 → 全程无卡密提示。
手段不限（补丁 / 代理 DLL / 重签包 / 启动器+注入器），只要原版能跑、功能全通。

先自己实测 P1–P5（能否到窗口 / 动态加载网络库 / 有无出站 / 断网对照 / 钥匙在哪），再报 RUNTIME / GATE / DELIVERY 三行。
旧报告只能当猜测；M0 全貌没出来前不许造交付物；结论没证据就标"待验"。

本阶段只做"旁路 + 可用"；改 UI / 接我自己的授权平台是后面的事，不要提前做。
```
