# 模板 · triage（快筛画像卡）

**这份模板用来干什么**：在动任何交付物之前，用 20 分钟把目标压成一张一行一字段的画像卡。
卡上六个字段是整个上游闸的判据 —— 卡不齐，后面的 static / dynamic / final 一律不许开工。
本模板只提供骨架与占位符，值必须是本目标实测出来的，抄别人的值等于没做。

> 上面第 1–5 段是**客户交付口径**（本阶段先写草稿，数值留空；到 final 阶段必须换成实测值，占位符 `<>` 全部消掉）。

## 1 结论（≤3 行：能不能用 / 到哪一步 / 卡在哪）
- 到哪一步：<只能看懂结构 | 能改到能用 | 能完全自己接管 | 现在做不了>
- 卡在哪：<卡点一句话 + 证据编号；没有卡点写「无」>
- 能不能用：<只按已有证据说一句；没跑过就写「未验证」>

## 2 已确认（每条：客户能听懂的一句话 + 证据 ID + 强度：强 / 中 / 弱）
- <客户能听懂的那句话>（`E-001`；强：同输入同输出可复现，命令与输出都能贴）—— 原始记录 `artifacts/<tool>-<时间>.json`
- <客户能听懂的那句话>（`E-002`；强：两路独立验证一致，不只是重复跑）—— 原始记录 `artifacts/<tool>-<时间>.json`
- 只有一次观测、没有可复跑命令的线索不进本段，写进第 3 段。

## 3 仍未知（每条：未知什么 + 为什么未知 + 缺什么才能知道）
- <未知什么>｜为什么未知：<环境限制 / 证据缺口 / 授权没给>｜还缺：<补什么才能知道>
- <未知什么>｜为什么未知：<同上>｜还缺：<同上>

## 4 下一步（省事路线 / 彻底路线 / 不建议做的事，各一条）
- 省事路线：<最小动作 + 拿到什么 + 大概要花多少功夫（区间 + 判断依据）>
- 彻底路线：<要补的证据或要动的位点 + 代价与工期>
- 不建议做：<哪条路会白费或越界，为什么>

## 5 怎么复查（复查单路径 + 关键重放命令 + 期望看到什么）
- 复查单：`python Tool/scripts/case_state.py recheck --case work/<case>` → 生成 `work/<case>/recheck.md`（目标哈希 / 环境 / 重放命令）
- 重放：<把本域的复跑命令原样抄到这里；Windows 的 cmd 与 PowerShell 都能直接粘>
- 期望：<关键字段或输出片段>；对不上先查「已知会变」（在线服务 / 证书 / IP / 时钟）

## 6 占位符约定

- `{{case}}`：案例目录名（如 `项目A`、`_p2fixture`）
- `{{target}}`：目标文件或目标的绝对身份描述（路径按仓库相对写，勿写本机盘符）
- `{{date}}`：执行日期，形如 `2026-10-24`
- `{{value}}`：实测值；未知就写 `未知（待测：<用什么手段测>）`，留空等于撒谎

## 7 画像卡（六字段，逐行填，一行一个值）

载体：{{value}}（PE/ELF/APK/Electron/JVM/脚本/前端包/固件…… 含位数与体积）
保护：{{value}}（无壳 / 壳名与节名 / 完整性自检 / 反调试 / 混淆器；无则写 无）
授权权威：{{value}}（校验落在哪：本地常量 / 本地签名 / 在线接口 / 硬件绑定；谁说了算）
改动面：{{value}}（要动的最小单元：磁盘字节 / 内存补丁 / 代理 DLL / 重打包 / 服务端）
检测器：{{value}}（目标自带的检测手段 + 我们可用的判据：字符串、断点、返回值、抓包）
交付壁垒：{{value}}（做完能不能拿走：签名校验 / 联网激活 / 自毁 / 平台审核 / 无）

## 8 卡片抬头（不影响六字段，但回执要引用）

- 案例：`{{case}}`
- 目标：`{{target}}`
- 日期：`{{date}}`
- 授权口径：自建夹具 / 用户提供样本 / 书面授权范围（照实写一句）

## 9 三行口径（能不能赢 / 天花板 / 第一刀）

- 能不能赢：可赢 / 部分可赢 / 不可赢（判据写在后两行）
- 赢的天花板：能进主界面但功能受限 / 功能全通但留残迹 / 全通且无残迹
- 第一刀切哪：一句话说出下一个动作（带命令或工具名）

## 10 收尾自检

- 六字段是否都在，且都不是 `{{value}}`
- 每个值是否能指向一条实测（命令 + 输出）
- 授权口径那一句是否写清「范围由谁声明」
