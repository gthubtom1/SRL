# 模板 · static（静态分析记录）

**这份模板用来干什么**：把「只看不跑」的那一段落成可复查的记录 —— 目标怎么装进来、入口在哪、
关键判断落在哪个函数、每条结论凭哪条证据成立。它的产物是**证据表**，不是心得。
每条结论都必须能被人照着同一命令复现；复现不了的结论一律降级为「假设」。

> 上面第 1–5 段是**客户交付口径**：本阶段先写草稿，到 final 阶段必须换成实测值。第 1 段「结论」≤3 行是硬约束，写不下就挪进第 3 段。

## 1 结论（≤3 行：能不能用 / 到哪一步 / 卡在哪）
- 到哪一步：<只能看懂结构 | 能改到能用 | 能完全自己接管 | 现在做不了>
- 卡在哪：<卡点一句话 + 证据编号；没有卡点写「无」>
- 能不能用：<只按已有证据说一句；没跑过就写「未验证」>

## 2 已确认（每条：客户能听懂的一句话 + 证据 ID + 强度：强 / 中 / 弱）
- <客户能听懂的那句话>（`E-001`；强：同输入同输出可复现，命令与输出都能贴）—— 原始记录 `artifacts/<tool>-<时间>.json`
- <客户能听懂的那句话>（`E-002`；强：两路独立验证一致，不只是重复跑）—— 原始记录 `artifacts/<tool>-<时间>.json`
- 只有一次观测、没有可复跑命令的线索不进本段，写进第 3 段。

## 3 仍未知（每条：未知什么 + 为什么未知 + 缺什么才能知道）
- <未知什么>｜为什么未知：<环境限制 / 证据缺口 / 授权没给>｜还缺：<补什么才能知道>
- <未知什么>｜为什么未知：<同上>｜还缺：<同上>

## 4 下一步（省事路线 / 彻底路线 / 不建议做的事，各一条）
- 省事路线：<最小动作 + 拿到什么 + 大概要花多少功夫（区间 + 判断依据）>
- 彻底路线：<要补的证据或要动的位点 + 代价与工期>
- 不建议做：<哪条路会白费或越界，为什么>

## 5 怎么复查（复查单路径 + 关键重放命令 + 期望看到什么）
- 复查单：`python Tool/scripts/case_state.py recheck --case work/<case>` → 生成 `work/<case>/recheck.md`（目标哈希 / 环境 / 重放命令）
- 重放：<把本域的复跑命令原样抄到这里；Windows 的 cmd 与 PowerShell 都能直接粘>
- 期望：<关键字段或输出片段>；对不上先查「已知会变」（在线服务 / 证书 / IP / 时钟）

## 6. 占位符约定

- `{{target}}`：被分析文件（仓库相对路径）
- `{{tool}}`：本次实际用的工具（IDA / radare2 / jadx / strings / objdump …）
- `{{addr}}`：地址（写清口径：文件偏移 / RVA / VA，三者不许混用）
- `{{fact}}`：一条可判真伪的事实句

## 7. 目标与加载

- 文件：`{{target}}`
- 类型与位数：{{value}}（用什么命令判的写在这里）
- 哈希：{{value}}（保留原始值，改过就换哈希并注明「已改」）
- 加载方式：`{{tool}}` + 加载基址/镜像基址：{{addr}}

## 8. 侦察：入口与外部面

- 入口点 / 主函数：{{addr}}
- 导入与外部调用：{{value}}（列出与授权、加密、网络相关的那些）
- 字符串与资源：{{value}}（按可读性/编码分组：ASCII / UTF-16 / 压缩资源）
- 配置与常量：{{value}}（URL、路径、魔数、密钥长度等，敏感值只记录形态）

## 9. 关键逻辑定位

- 候选函数清单（函数名或地址 → 为什么可疑）：{{value}}
- 交叉引用路径（谁调用它、它的返回值被谁用）：{{value}}
- 分叉点：{{addr}}（判定成立/不成立的分支，写清两侧走向）
- 位点结论：{{fact}}

## 10. 证据（每条事实一行，缺一行就不算结论）

| 编号 | 结论 | 怎么看出来的 | 指针 |
| :-- | :-- | :-- | :-- |
| F-001 | {{fact}} | {{tool}} 命令 / 窗口 | `{{target}}:{{addr}}` |
| F-002 | {{fact}} | {{tool}} 命令 / 窗口 | `{{target}}:{{addr}}` |

证据等级（照实标，别抬级）：

- 强：同输入同输出可复现（命令 + 原始输出都能贴出来）
- 中：只有一次观测，但能重复命令
- 弱：靠经验推断，未验证 —— 写进「假设」小节，不进上表
