# 模板 · static（静态分析记录）

**这份模板用来干什么**：把「只看不跑」的那一段落成可复查的记录 —— 目标怎么装进来、入口在哪、
关键判断落在哪个函数、每条结论凭哪条证据成立。它的产物是**证据表**，不是心得。
每条结论都必须能被人照着同一命令复现；复现不了的结论一律降级为「假设」。

## 占位符约定

- `{{target}}`：被分析文件（仓库相对路径）
- `{{tool}}`：本次实际用的工具（IDA / radare2 / jadx / strings / objdump …）
- `{{addr}}`：地址（写清口径：文件偏移 / RVA / VA，三者不许混用）
- `{{fact}}`：一条可判真伪的事实句

## 1. 目标与加载

- 文件：`{{target}}`
- 类型与位数：{{value}}（用什么命令判的写在这里）
- 哈希：{{value}}（保留原始值，改过就换哈希并注明「已改」）
- 加载方式：`{{tool}}` + 加载基址/镜像基址：{{addr}}

## 2. 侦察：入口与外部面

- 入口点 / 主函数：{{addr}}
- 导入与外部调用：{{value}}（列出与授权、加密、网络相关的那些）
- 字符串与资源：{{value}}（按可读性/编码分组：ASCII / UTF-16 / 压缩资源）
- 配置与常量：{{value}}（URL、路径、魔数、密钥长度等，敏感值只记录形态）

## 3. 关键逻辑定位

- 候选函数清单（函数名或地址 → 为什么可疑）：{{value}}
- 交叉引用路径（谁调用它、它的返回值被谁用）：{{value}}
- 分叉点：{{addr}}（判定成立/不成立的分支，写清两侧走向）
- 位点结论：{{fact}}

## 4. 证据（每条结论一行，缺一行就不算结论）

| 编号 | 结论 | 怎么看出来的 | 指针 |
| :-- | :-- | :-- | :-- |
| F-001 | {{fact}} | {{tool}} 命令 / 窗口 | `{{target}}:{{addr}}` |
| F-002 | {{fact}} | {{tool}} 命令 / 窗口 | `{{target}}:{{addr}}` |

证据等级（照实标，别抬级）：

- 强：同输入同输出可复现（命令 + 原始输出都能贴出来）
- 中：只有一次观测，但能重复命令
- 弱：靠经验推断，未验证 —— 写进「假设」小节，不进上表
