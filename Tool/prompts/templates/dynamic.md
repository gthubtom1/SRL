# 模板 · dynamic（动态分析记录）

**这份模板用来干什么**：把「跑起来看」的那一段落成台账。动态分析最容易出的事故是**地址串了**：
dump 里拿到运行时 VA，报告里却按镜像基址算 RVA，于是后续每一步都错位。
所以本模板的核心是一张**三列地址台账**：RVA、VA、基址，一个位点占一行，换算关系写在表头。
结论只认「断点命中 + 寄存器/内存实测值」，不认「看起来像」。

## 占位符约定

- `{{target}}`：被调试文件（仓库相对路径）
- `{{base}}`：本次会话的模块基址（ASLR 前后都写，注明是哪一次）
- `{{rva}}` / `{{va}}`：相对虚拟地址 / 虚拟地址
- `{{bp}}`：断点位置与类型（INT3 / 硬件 / 内存写）
