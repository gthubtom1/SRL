# Android 真实练习样本（教学靶场 APK）

> 来源：[ev-flow/apk-samples](https://github.com/ev-flow/apk-samples) 的 `vulnerable-samples/`。
> 这些都是**公开的安全教学靶场 APK**（DIVA、InsecureBankv2、AndroGoat、allsafe、OVAA、Vuldroid），
> 专门设计来练 Android 逆向/漏洞挖掘，**不是恶意病毒**。个人自用，随仓库分发。

| APK | 说明 |
|---|---|
| `diva.apk` | DAMN Insecure and Vulnerable App（经典 Android 漏洞练习） |
| `InsecureBankv2.apk` | 不安全银行 App（越权/存储/加密练习） |
| `AndroGoat.apk` | 综合 Android 安全练习靶场 |
| `allsafe.apk` | 多漏洞 Android 靶场 |
| `ovaa.apk` | OWASP Vulnerable Android App |
| `Vuldroid.apk` | 多类漏洞 Android 靶场 |

用途：`seep_apk_info` / `seep_apk_decompile` / `seep_apk_unpack` / `seep_apk_smali_search` 真实样本验证。
