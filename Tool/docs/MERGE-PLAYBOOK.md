# 外部能力吸收入口

当前扩展与回滚流程见 [EXTEND](EXTEND.md)，功能范围见 [REQUIREMENTS](../../REQUIREMENTS.md)。只为明确需求吸收所需能力，核对来源、许可、依赖、准入、真实执行及回滚；不因外部项目存在就整体移植。

REA 在本仓是部分方法和能力来源，不是完整运行时依赖。工具发现/控制方式选择与失败降级由现有入口承担；`engine-tiers.json` 未接入自动反编译。现状见 [扩展能力](EXT-ASSETS.md)。

旧“只能追加、不能修改或删除既有内容”“改引擎表即可生效”“存在性检查等于完成”方案已经淘汰。必要修复按具体反例最小修改，保留用户材料；不得恢复取消项或用旧计数制造通过。

修复后运行受影响检查及完整 `python Tool/scripts/check.py --strict`，分别核验源码、正式部署和新进程加载。完整结果只记 [CURRENT-STATE](../../docs/CURRENT-STATE.md)，不另立进度方案。提交、发布须有用户授权。
