## 核心结论（一屏）

| 项 | 结论 |
|---|---|
| 保护形态 | 运行期改页保护 + 字符串加密 + 资源 zstd 压缩（非加密壳） |
| 货物在哪 | **21MB 的 `.rsrc`/DATA102（XWGZSkins）= 皮肤包**，不在 `.ace0` 混淆层 |
| 首选手法 | `seep_pe_resources` 剥离资源 → zstd 解压 → 拿到功能资产 |
| 大坑 | 全量反编译、壳层死磕、PAGE_GUARD、索要卡密（导入表零网络 API） |
| 反调试 | Explorer 原生启动拉起窗口，再 MinHook；不用侵入式页守卫 |
