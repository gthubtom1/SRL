# Agent Note: 全量反编译 26MB 带壳程序（binary_overview / list_procedures）

Status: rejected — `.ace0` 混淆 + 21MB 资源导致反编译器陷入海量虚假控制流，280 秒超时被杀。

## Problem

拿到一个 26MB、`.ace0`(4.6MB, 熵7.25) + `.rsrc`(21MB, 熵8.0) 的加壳样本，
想"先整体反编译看看"。

## Proposal

直接 `binary_overview` / `list_procedures` 全量分析。

## Alternatives considered

- **先判壳+剥离资源，再定点反编译** ——
  最强理由：节区熵 >7 且存在 >1MB 非标节时，全量分析必然超时；资源里才是货物。
  采纳原因：实测全量 280s 超时；定点+资源剥离秒级出结果。

## Consequences

- **可复用判据**：**节区熵 >7 且存在 >1MB 非标节 → 禁止全量反编译**，改用 `seep_pe_resources` 剥离 + `seep_decompile_auto` 定点。
- **代价**：需要先做静态画像（多一步），但省下大量超时。
