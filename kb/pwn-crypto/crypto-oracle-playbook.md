# 密码学 oracle 速查（RSA/ECB/CBC/PRNG）

> 配套 `Tool/skill/pwn-crypto/references/crypto-attacks.md`。先写假设，再做回代。

## 1. 开局三问

1. 有没有填充（PKCS#1/自定义）？
2. 两组密文是不是**同一消息**？
3. 模数是否互质/是否同一 `n`？

回答不了就先做小实验，不要直接套攻击脚本。

## 2. RSA

| 情形 | 条件 | 判据 |
|---|---|---|
| 小指数无填充 | `e=3` 且 `m^e<n` | `iroot(c,e)` 精确，`pow(m,e,n)==c` |
| 共模 | 同 `n`、同 `m`、`gcd(e1,e2)=1` | 两组回代都成立 |
| Håstad 广播 | 同 `m`、`e=3`、≥3 组互质 `n` | CRT 后开方精确，`m^e<M` |
| 共享素数 | `gcd(n1,n2)>1` | 分解成功且私钥解密可读 |
| Wiener | `d` 很小 | 连分数收敛出 `d`，回代成立 |
| Fermat | `p,q` 接近 | `a^2-n` 为完全平方 |

```python
m = iroot(c, e)
assert pow(m, e, n) == c, "有填充或 m^e>=n"
```

**失败判据**：开方不精确、两组不能同时回代、恢复的 `m` 不可读但强行宣布成功。

## 3. ECB

- 找 16 字节重复块；相同明文块 → 相同密文块。
- 字节逐位 oracle：控制前缀对齐，逐字节爆破；cut-and-paste 重排块。
- **判据**：块相等关系可复现；oracle 返回块命中字典；拼接后目标字段被接受。
- **误判**：把随机碰撞当 ECB；块大小不是 16（可能是 8/32）。

## 4. CBC

```text
P[i] = D(C[i]) xor C[i-1]
改 C[i-1] 使 P[i] 按预期翻转；第一块改 IV
```

- padding oracle：只在 padding 合法时给侧信道，逐字节恢复；注意错误粒度。
- **判据**：解密结果目标字节等于期望，且 padding/格式校验通过。
- **误判**：改错块索引；把 MAC 错误当 padding 错误；IV 不在可控范围。

## 5. PRNG

| 类型 | 恢复方式 | 判据 |
|---|---|---|
| MT19937 | 624 个连续 32-bit 输出克隆状态 | 下一输出逐位一致 |
| C `rand()`/LCG | 连续输出解 `a,c,m` 或时间种子爆破 | 预测值逐位一致 |
| Java `Random` | 48-bit 状态，连续输出推 | 跨拒绝采样仍正确 |

- `randint/randrange` 有拒绝采样，按 `getrandbits` 记账。
- **误判**：只验证“分布像”；消耗了额外随机数。

## 6. 证书/签名

```bash
openssl x509 -text -noout -in cert.pem
openssl verify -CAfile ca.pem cert.pem
```

- 弱情形：`e=1`、`e=3` 无填充、DER 解析差异、弱哈希、自签信任。
- **判据**：目标验证器接受伪造签名/证书，且 `openssl verify` 或程序返回成功。
- **误判**：只改文件没改信任链；把解析差异当签名伪造。
